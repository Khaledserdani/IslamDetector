# ISLAM FREE AGENT — تطبيق Android مستقل

## المبدأ
هذا التطبيق موجّه للعمل من الهاتف نفسه. لا يحتاج إلى كمبيوتر أو Ollama أو جسر شبكة محلي أو خادم مدفوع. المهام المحلية والمختبر الحسابي والجدولة تُدار داخل Android.

## الوظائف الموجودة في التطبيق
- واجهة عربية RTL.
- مهام محلية: إضافة، إكمال، إعادة فتح، وحذف، مع حفظها على الهاتف.
- مختبر DC للمقاومات الخطية متعدد العقد، بمصدر جهد مثالي واحد بين العقدة `vcc` والأرضي `0`.
- حساب جهود العقد وتيار المصدر والتحقق من خطأ قانون كيرشوف للتيارات KCL.
- يستطيع مخطط Qwen اقتراح خطة لمحاكاة DC بصيغة JSON محددة، ويمررها إلى محرك المختبر المسموح بعد التحقق من المدخلات.
- لا تبدأ محاكاة الوكيل إلا بعد معاينة الدارة وموافقة المستخدم.
- دفتر نتائج محلي محدود إلى 200 تجربة، يحفظ المدخلات والنتائج وإصدار المحرك ومصدر التنفيذ والطابع الزمني وفحص KCL.
- نتائج التجارب المجدولة تُسجل في دفتر النتائج نفسه، مع تمييزها عن التجارب التي وافق عليها المستخدم.
- شاشة المختبر تعرض سجل النتائج وملخص قائمة التجارب.
- قائمة تجارب DC محفوظة محلياً.
- جدولة WorkManager كل 15 دقيقة كحد أدنى، تنفذ تجربة واحدة في كل مرة داخل نافذة الجزائر 20:00–06:00.
- تشغيل الجدولة وإيقافها ومراجعة حالة قائمة التجارب من الواجهة.
- لوحة GitHub اختيارية للقراءة المباشرة من الهاتف؛ لا تنفذ تعديلات أو دمجاً تلقائياً.
- محرك LiteRT-LM مضاف تجريبياً لتشغيل Qwen3-0.6B على CPU الهاتف، مع تنزيل النموذج عبر Wi-Fi وفحص SHA-256 قبل التحميل.

## الذكاء الاصطناعي المحلي — حالة تجريبية
- ملف النموذج منفصل عن APK؛ حجمه 613,722,264 بايت (نحو 586 MiB).
- التنزيل من Hugging Face يتطلب اتصال Wi-Fi مرة واحدة؛ بعد اكتمال التنزيل لا يحتاج توليد الردود إلى الإنترنت.
- النموذج Qwen3-0.6B بترخيص Apache 2.0، ومحرك LiteRT-LM Android 0.18.0.
- التطبيق يفحص الحجم والبصمة قبل تمرير الملف للمحرك.
- النموذج يعمل على CPU حالياً لتجنب افتراض توافق GPU/NPU غير المثبت على الهاتف.
- نجاح البناء واختبارات الوحدة لا يثبتان أن النموذج حمّل الأوزان وأنتج إجابة على جهاز حقيقي. اختبار realme C75x مطلوب قبل اعتماد هذه الوظيفة نهائياً.

## حدود التشغيل
- WorkManager مجدول بأفضل جهد؛ قد يؤخر Android العمل بسبب Doze وتوفير البطارية. لا يضمن التنفيذ في الدقيقة المحددة ولا التشغيل المتواصل طوال الليل.
- المختبر المتاح داخل APK حالياً DC مقاومات خطية ومصدر جهد مثالي واحد فقط. لا يدعم بعد AC أو RLC أو الترانزستورات أو الدوائر الرقمية أو SPICE العام.
- محركات Python المرجعية لـRLC وAC لا تعمل تلقائياً داخل APK؛ يلزم نقلها إلى Android واختبارها قبل إظهارها كقدرات قابلة للتنفيذ.
- فحص KCL هو تحقق عددي داخلي من الحل، وليس تحققاً مستقلاً من صحة النموذج ولا قياساً مادياً.
- توجد محركات/اختبارات Python مرجعية في المستودع، لكنها ليست كلها مدمجة في تطبيق Android ولا يجوز وصفها بأنها مختبرات هاتف جاهزة.
- لا توجد صلاحية للوكيل كي يغيّر ملفات المشروع أو يدمج تغييرات GitHub تلقائياً.
- هذا الدمج يستخدم محركات المختبر الخاصة بتطبيق ISLAM FREE AGENT؛ لا يضم وحدة `:lab` التابعة لتطبيق كاشف المعادن ولا يخلط مستودعات أو بيانات المشروعين.
- لا يوجد اعتماد على اشتراك أو API مدفوع أو تشغيل سحابي دائم.

## اختبارات Android الآلية
- مقسم جهد 10V بمقاومتين 1kΩ: العقدة الوسطى 5V والتيار 5mA.
- فروع متوازية.
- رفض الشبكات العائمة والمقاومات غير الصالحة.
- حفظ قائمة التجارب وتحديث حالاتها.
- حدود نافذة العمل الليلية.
- اختبار فتح الواجهة وظهور عناصر المختبر والجدولة والذكاء المحلي، مع التحقق من عدم ظهور عناصر ربط الكمبيوتر القديمة.
- اختبار سلامة APK وفحص محتوياته ضمن CI.

## البناء
```bash
gradle --no-daemon :agent:testDebugUnitTest :agent:assembleDebug
```

APK الناتج:
`agent/build/outputs/apk/debug/agent-debug.apk`

نجاح البناء والاختبارات الآلية لا يثبت اختبار الهاتف الحقيقي أو نجاح استدلال النموذج محلياً. لا يُعلن الإصدار النهائي قبل التحقق من تحميل النموذج وتوليد رد، ثم التثبيت والتشغيل على الجهاز المستهدف.
