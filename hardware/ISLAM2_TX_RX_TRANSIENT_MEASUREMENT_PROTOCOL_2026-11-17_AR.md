# بروتوكول قياس نبضة TX واستجابة RX — ISLAM 2
التاريخ: 2026-11-17
الفرع: hardware/islam-nextgen-final-platform
الحالة: بروتوكول مختبر قبل تثبيت قيم الحماية؛ ليس تعليمات تشغيل ميداني ولا تصريحاً بتوصيل الدائرة مباشرة.

## 1) الهدف
الحصول على بيانات حقيقية لملف إسلام النشط ومسار الإرسال/الاستقبال حتى نحدد:
- جهد RX الأقصى وقطبيته وعرض النبضة والذيل.
- تيار TX وشكل تناقصه عند الإطفاء.
- رنين RX وQ وزمن الاضمحلال.
- زمن استعادة حاجز الحماية وAFE.
- أول نافذة زمنية صالحة لإشارة الهدف مع SNR قابل للقياس.

لا تُستنتج قيم الحماية من ملف DD32 أو DD23 أو من أرقام أوراق بحثية لملفات أخرى. ملف Mono Spiral 35×35 هو مسار التطوير النشط وفق سجل المشروع، لكن عدد لفاته وL/R الفعليين يجب أن يؤخذا من النسخة المادية التي ستُقاس، لا من افتراض.

## 2) بوابة السلامة قبل أي نبضة
- لا تُشغّل مرحلة TX قبل مراجعة MOSFET وGate driver وTVS/snubber ومسار التيار وحدود الطاقة.
- استخدم مزود طاقة مختبرياً محدود التيار، مع فيوز مناسب ومفتاح فصل طارئ.
- قياس نبضة flyback يحتاج مجساً تفاضلياً عالي الجهد مصنفاً للذروة والـcommon-mode والـtransient المطلوب. لا تستخدم مجس oscilloscope أرضياً عادياً على عقدة عائمة أو عالية الجهد.
- لا تفصل أرضي الأوسيلوسكوب ولا تلغِ التأريض الوقائي كحل قياس.
- افحص تصنيف المجس والكابلات والـattenuation والـbandwidth وCAT/working voltage قبل التوصيل.
- ابدأ بطاقة نبضة منخفضة وبتيار محدود، ثم زدها تدريجياً فقط بعد التأكد من سلامة شكل الموجة والحرارة.
- لا توصل OPAMP3 أو ADC3 أو لوحة MCU أثناء قياس النبضة الخام. استخدم حمل/واجهة اختبار تتحمل الجهد، ثم أضف طبقات الحماية بعد التحقق.
- إذا لم تتوفر مجسات مناسبة أو خبرة قياس نبضات عالية الجهد، ينفذ هذا القياس في مختبر إلكترونيات مؤهل.

## 3) نقاط القياس
| الرمز | النقطة | ما يقاس |
|---|---|---|
| TP-TX1 | تيار TX عبر shunt منخفض الحث ومقاس | I_TX(t)، ذروة التيار، di/dt، زمن الإطفاء |
| TP-TX2 | طرفا TX differential | جهد الملف، flyback، رنين/overshoot |
| TP-RX1 | طرفا RX دون AFE (open-circuit) | V_RX differential، القطبية، الذروة، عرض النبضة |
| TP-RX2 | RX مع damping فقط | أثر التخميد على الرنين والذيل |
| TP-RX3 | بعد حاجز HV | الجهد المتبقي، زمن الفصل/العودة |
| TP-AFE1 | مدخل OPAMP3/مرحلة AFE | مجال common-mode والتفاضلي، هل يتجاوز الحدود؟ |
| TP-AFE2 | خرج OPAMP3 | clipping، recovery، settling |
| TP-ADC | PB1/ADC3_IN1 | مجال الجهد وتوقيت العينة والـover/undershoot |

## 4) تسلسل القياس
### المرحلة A — الملف دون طاقة
1. قس R_DC لكل ملف بأداة مناسبة، مع تسجيل مقاومة الأسلاك والموصلات منفصلة إن أمكن.
2. قس L عند أكثر من تردد اختبار إن أمكن، وسجل تردد القياس وسعة الإشارة.
3. قس الرنين الذاتي أو استخرج Q من استجابة منخفضة الطاقة، وسجل طريقة القياس.
4. افحص العزل بين TX وRX وبين الملفات والهيكل/الشيلد.
5. سجّل هندسة الملف، عدد اللفات الفعلي، طول السلك، قطره، المسافات، واتجاه اللف.

### المرحلة B — TX وحده
1. اترك RX وAFE مفصولين عن الإلكترونيات الحساسة.
2. استخدم نبضة قصيرة وطاقة منخفضة ضمن حدود المكونات.
3. سجل I_TX(t) وV_TX(t) مع مجسات مناسبة.
4. استخرج L·di/dt وذروة flyback وعرضها، ولا تستخدم علاقة تقريبية وحدها بديلاً عن القياس.
5. كرر على درجات التيار والطاقة المسموح بها، مع مراقبة حرارة MOSFET والمقاومة/المشبك.

### المرحلة C — اقتران TX/RX
1. ثبت الملفين في الوضع الهندسي النهائي وعلى مسافة/تداخل ثابتين.
2. سجل RX open-circuit عند TX off/on، مع حفظ waveform خام.
3. كرر مع polarity أو نمط نبضة مختلف فقط إذا كان تصميم TX يدعمه فعلياً.
4. لا تضع مشبك حماية على RX في أول قياس مرجعي؛ استخدم مجساً عالي المعاوقة مناسباً للجهد.
5. لا تترك RX مفتوحاً في اختبار طاقة عالية إلا إذا كان ذلك ضمن تصنيف العزل والمجس والملف. ابدأ بطاقة منخفضة.

### المرحلة D — المقارنة بين الحمايات
لكل خيار حماية:
1. سجل V_RX قبل الحماية وبعدها بالتزامن.
2. سجل تيار الحماية أو استنتجه بقياس موثق عبر عنصر قياس مناسب.
3. سجل زمن عودة العقدة إلى مجال AFE المسموح.
4. قس noise floor بعد الاستقرار.
5. كرر دون هدف ومع هدف مرجعي ثابت، وقارن فرق الإشارة.
6. كرر 1000 نبضة أو عدد دورات محدد لاحقاً مع مراقبة الحرارة والانجراف؛ العدد النهائي يحدد وفق عمر الاختبار والقدرة.

## 5) نموذج البيانات الواجب حفظه
لكل تشغيل احفظ CSV/ملف خام يتضمن:
- run_id، التاريخ، إصدار ملف البحث، revision الدارة.
- هوية TX/RX وعدد اللفات والأبعاد وR/L/Q ودرجة الحرارة.
- V_supply، I_TX_peak، pulse_width، repetition_rate، clamp/snubber configuration.
- نوع المجس، نسبة attenuation، bandwidth، sample_rate، coupling، نقاط القياس.
- waveform timestamps وV_TX وI_TX وV_RX وV_after_protection وV_AFEout.
- نوع الهدف، مادته/أبعاده/اتجاهه/المسافة/الارتفاع، أو blank/no-target.
- كل إعدادات التربة والارتفاع والحركة إذا أجريت اختبارات لاحقة.
- ملاحظات saturation، ringing، clipping، thermal drift، fault flags.

## 6) معايير التوقف الفوري
أوقف الاختبار فوراً عند:
- تجاوز تصنيف أي عنصر أو مجس أو كابل.
- overshoot غير متوقع أو oscillation يتصاعد.
- ارتفاع حراري سريع أو رائحة/دخان أو صوت تفريغ.
- فشل clamp/snubber أو انهيار جهد التغذية.
- وصول جهد غير محمي إلى MCU/ADC/OPAMP.
- عدم استقرار القياس أو فقد التأريض الوقائي.

## 7) المخرجات المطلوبة قبل BOM الحماية
- جدول Vpk وpolarity وpulse width وring-down لكل من TX وRX.
- قياس L/R/Q للملفين.
- I_TX(t) وdi/dt.
- قياس زمن recovery لكل خيار حماية.
- SNR/PSD قبل وبعد الحماية.
- اختيار موثق لطوبولوجيا الحماية وقيمها، مع worst-case tolerance/temperature.
- مخطط نهائي مع حدود جهد/تيار كل عقدة ومراجعة مطابقة لداتا شيت كل عنصر.

## 8) ما لم يتم إنجازه
لم تُنفذ القياسات فعلياً، ولم يتم بناء منصة اختبار أو شراء مجس/لوحة/قطع. هذه وثيقة إجراء ومواصفات تسجيل فقط. لا تعتبر الأرقام أو الأزمنة مثبتة حتى تُملأ ببيانات مختبرية قابلة لإعادة التكرار.
