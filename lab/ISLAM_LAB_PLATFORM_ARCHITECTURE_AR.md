# ISLAM LAB — منصة محاكاة الدارات والتكامل مع ChatGPT

الحالة: تأسيس معماري — لم يُنفذ محرك SPICE بعد.
الفرع: `lab/islam-spice-platform-foundation`

## الهدف
إنشاء مختبر دارات إلكترونية قابل للتثبيت على Android والكمبيوتر كتطبيق ويب تقدمي (PWA)، يعمل محلياً قدر الإمكان، ويتيح لاحقاً لـChatGPT التحكم في المشاريع والمحاكاة والنتائج عبر واجهة MCP موثقة وآمنة.

## قرار البنية
1. **واجهة PWA عربية RTL**: محرر مخطط، مكتبة مكونات، نافذة خصائص، موجات، قياسات، وسجل تجارب.
2. **محرك المحاكاة**: ngspice compiled to WebAssembly داخل Web Worker، حتى تعمل المحاكاة محلياً ولا تُرفع الدارات الخاصة إلى خادم افتراضياً.
3. **نموذج مشروع موحد**: JSON منظم هو المصدر الأساسي للمخطط والمكونات والاتصالات والإعدادات؛ منه يُولّد SPICE netlist.
4. **ملفات قابلة للنقل**: مشروع `.islamlab.json`، netlist `.cir`، نتائج CSV، ورسوم/تقارير قابلة للتصدير.
5. **واجهة MCP منفصلة**: أدوات محددة لإنشاء المشاريع وتعديل الدارات وتشغيل المحاكاة واسترجاع النتائج والتوثيق. لا يُسمح بتنفيذ shell أو كود اعتباطي من طلبات النموذج.
6. **طبقة تدقيق**: كل تغيير ومحاكاة ينتج revision وrun ID مع المدخلات وإصدار المحرك وملخص النتائج.

## لماذا محرك داخل المتصفح؟
- تشغيل محلي يقلل تكلفة الخوادم ويحافظ على خصوصية الدارات.
- يمكن تثبيت PWA على الهاتف وإتاحتها دون اتصال بعد تحميل ملفات التطبيق والمحرك.
- يتيح بناء واجهة متاحة للمستخدم حتى إن لم يكن اتصال ChatGPT متاحاً.
- لا يعني ذلك أن ChatGPT يستطيع تلقائياً الوصول إلى محاكاة المتصفح؛ يلزم جسر MCP مستقل ومصرح به.

## التكامل مع ChatGPT — شرط واقعي
ChatGPT يتصل بخادم MCP بعيد عبر HTTPS أو قناة نفق مدعومة، ولا يتصل مباشرة بخدمة محلية عادية على الهاتف. وثائق OpenAI الحالية تذكر أن دعم خوادم MCP المخصصة والكتابة/التعديل متاح لخطط Business وEnterprise/Edu، بينما لا نعد مستخدم Free بإمكانية ربط MCP مخصص مباشرة. لذلك:
- نبني عقد MCP من البداية ونختبره مستقلاً.
- نُبقي واجهة المختبر تعمل دون ChatGPT.
- لا نفتح خادماً عاماً بلا مصادقة.
- لا نضع مفاتيح أو أسراراً في تطبيق الهاتف أو المستودع.
- لا نعتبر الربط مكتملاً حتى يظهر اتصال فعلي ناجح وتُنفذ تجربة من ChatGPT.

## وظائف MCP المقترحة
- `lab_list_projects`, `lab_create_project`, `lab_get_project`
- `lab_add_component`, `lab_update_component`, `lab_connect_nodes`
- `lab_validate_circuit`, `lab_generate_netlist`
- `lab_run_analysis` (op / tran / ac / dc في الإصدار الأول)
- `lab_get_run`, `lab_get_waveform`, `lab_get_measurements`
- `lab_compare_runs`, `lab_export_project`, `lab_get_audit_log`

كل أداة تأخذ project_id وrevision صريحين عند الحاجة، وتعيد مراجع نتائج ثابتة. عمليات التعديل والتشغيل تُسجل؛ ولا تُقبل أوامر netlist خطرة أو مسارات ملفات حرة.

## خطة التنفيذ المرحلية
### المرحلة 0 — تأسيس (هذه المرحلة)
- تحديد بنية PWA + محرك WASM + MCP.
- تثبيت سياسة البيانات والأمان والتوثيق.
- مراجعة تراخيص أي مشروع مفتوح المصدر قبل إعادة استخدام كوده.

### المرحلة 1 — نواة SPICE قابلة للاختبار
- تشغيل ngspice WASM في Web Worker.
- إدخال netlist نصي أولاً قبل محرر الرسم.
- دعم .op و.tran و.ac و.dc.
- قراءة النتائج وعرض waveform وتصدير CSV.
- اختبارات مرجعية لدارات RLC وRC وMOSFET باستخدام نماذج موثقة.

### المرحلة 2 — محرر المخطط
- مكتبة مقاومة/مكثف/ملف/مصادر/دايود/BJT/MOSFET/أرضي.
- توصيل الشبكات وتوليد netlist حتمي.
- فحص floating nodes وغياب ground والوصلات غير الصالحة.

### المرحلة 3 — واجهة MCP
- تشغيل أدوات CRUD والتحقق والمحاكاة والنتائج.
- مصادقة قوية وصلاحيات منفصلة للقراءة والتعديل والتشغيل.
- سجل تغييرات كامل واختبارات رفض للمدخلات الضارة.

### المرحلة 4 — تثبيت ونشر
- PWA installable على Android والكمبيوتر.
- استضافة ملفات ثابتة مجانية حيثما أمكن، مع إبقاء المحاكاة محلية.
- نشر MCP فقط بعد اختيار قناة استضافة/نفق لا تتطلب كشف الخدمة أو أسرارها.
- لا نعد باستضافة سحابية مجانية مدى الحياة؛ أي خدمة طرف ثالث قد تغير شروطها.

## معايير قبول الإصدار الأول
- يعمل دون تسجيل دخول أو اشتراك لمحاكاة محلية أساسية.
- ينجح في اختبارات مرجعية ذات نتائج متوقعة ضمن tolerances معلنة.
- يصدر netlist وCSV وملف مشروع قابل لإعادة الفتح.
- يعرض إصدار المحرك والتحذيرات وأخطاء التقارب.
- لا يصف المحاكاة بأنها قياس عتادي.
- لا يُعلن تكامل ChatGPT قبل تنفيذ اختبار MCP فعلي من حساب مؤهل.

## نطاق ISLAM 2
تُنشأ داخل المختبر مجموعة مشاريع خاصة بـISLAM 2: ملف Mono Spiral 35×35، TX، RX، حماية MOSFET/TVS، front-end، DAC cancellation، وقياسات/مقارنات منفصلة. تبقى قيم المكونات افتراضات حتى توثيق مصدرها أو قياسها. لا يُستورد تصميم DD23 أو DD32 إلى المشروع النشط تلقائياً.


## شرط إلزامي: مجاني 100% دون اشتراك

هذا شرط تصميمي غير قابل للتفاوض:
- لا اشتراك أو رسوم ترخيص للمستخدم.
- لا مفاتيح API مدفوعة ولا رصيد استخدام.
- لا اعتماد إلزامي على خدمات AI سحابية أو قواعد بيانات مدفوعة.
- محرك SPICE يعمل محلياً على جهاز المستخدم، وتبقى المشاريع والنتائج محلية افتراضياً.
- لا تسجيل دخول إجباري ولا مدة تجريبية ولا إيقاف بعد عدد تشغيلات.
- اختيار مكونات مفتوحة المصدر ذات تراخيص تسمح بالاستخدام وإعادة التوزيع، مع توثيق كل ترخيص.
- لا نعد باستضافة أو نطاق مجاني مدى الحياة؛ لذلك يجب ألا تكون الاستضافة السحابية شرطاً لتشغيل المحاكي.

### قيد التكامل مع ChatGPT
واجهة MCP تُصمم كطبقة اختيارية مستقلة. لا يجوز أن يتطلب تشغيل ISLAM LAB اشتراك ChatGPT أو MCP. إذا لم يسمح حساب ChatGPT بالاتصال المباشر بخادم MCP، يبقى المختبر كاملاً وقابلاً للاستخدام مجاناً، مع مسارات تبادل محلية مفتوحة مثل ملفات المشروع وSPICE netlist وCSV والتقارير. لا يُدّعى وجود اتصال مباشر حتى ينجح اختبار فعلي من حساب المستخدم، ولا يُطلب من المستخدم دفع أي مبلغ لتفعيله.
