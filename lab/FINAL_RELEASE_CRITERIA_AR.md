# ISLAM LAB — معيار الإصدار النهائي

هذا الملف يحدد شروط اعتبار ISLAM LAB إصداراً نهائياً. نسخة المختبر الحالية 0.2.0 مرشح تطوير، ولا تحقق بعد شروط الإصدار النهائي.

## نطاق المنتج النهائي
- مختبر هندسي مستقل عن ISLAM DETECTOR، مع فصل واضح بين المحاكاة والقياس الحقيقي.
- محرك تجارب قابل للتوسعة مع تعريف النموذج وإصداره ووحداته وافتراضاته ومجال صلاحيته.
- إدخال قياسات حقيقية يدوياً واستيراد CSV والتحقق من صحة البيانات والوحدات.
- سجل تجارب محلي دائم: إنشاء وفتح وإعادة تسمية وحذف وتصدير واستيراد نسخ احتياطية.
- تحليل إحصائي قابل لإعادة الإنتاج، مع حفظ البيانات الخام ونتائج المعالجة كلٌ على حدة.
- رسوم بيانية بمحاور ووحدات ومقياس واضح، وتصدير CSV وتقرير قابل للمشاركة.
- وحدات مستقلة للمحاكاة الفيزيائية والإلكترونية؛ تشمل النواة الحالية مجال السلك ثلاثي الأبعاد، نبضة PI المختزلة، تحميل RX وحمايته، ونموذج OPA365 سلوكياً.
- توسعة النموذج إلى هدف موصل ثلاثي الأبعاد وتربة، والتحقق المتقاطع مع FEM وSPICE قبل اعتماد التصميم.
- واجهة عربية RTL، معالجة أخطاء مفهومة، وإمكانية استخدام الوظائف الأساسية دون إنترنت.

## بوابات القبول قبل الإصدار النهائي
1. اختبارات وحدات لكل الحسابات والحالات الحدية والتحقق من الوحدات، مع تقارب زمني/شبكي وميزانية طاقة.
2. تحقق متقاطع مستقل بين محرك AFE ومحاكي SPICE، وبين محرك الهدف ومحرك FEM؛ لا يكفي اتزان الطاقة الداخلي وحده.
3. اختبارات واجهة وتدفق كامل: إنشاء تجربة، حفظها، إغلاق التطبيق، إعادة فتحها، استرجاعها وتصديرها.
4. اختبار استيراد CSV لملفات سليمة ومعطوبة وكبيرة، مع منع فقدان البيانات بصمت.
5. اختبار APK على محاكي Android وإثبات التثبيت والتشغيل والتنقل وعدم الانهيار.
6. مراجعة أذونات التطبيق والخصوصية والتخزين وعدم طلب أذونات غير لازمة.
7. بناء Release موقّع بمفتاح إصدار محفوظ لدى مالك المشروع؛ لا يُسمّى debug APK إصداراً نهائياً.
8. نشر Release غير تجريبي مع رقم إصدار وسجل تغييرات وبصمة SHA-256، ثم تنزيله وفحصه فعلياً.

## ما لا يجوز ادعاؤه
- لا تُسمّى الموجة الاصطناعية قياساً حقيقياً.
- لا تُسمّى الإحصاءات محاكاة كهرومغناطيسية أو محاكاة SPICE.
- لا يُدّعى دعم أجهزة القياس أو اتصال ESP32 قبل تنفيذ البروتوكول واختباره على عتاد حقيقي.
- لا يُعلن الإصدار نهائياً قبل اجتياز جميع بوابات القبول أعلاه.

## الحالة الحالية
- 0.2.0: أساس هندسي متقدم؛ أضيفت نواة المجال، ومحرك نبضة PI بحلقة هدف مكافئة، ومحرك RX/AFE مع نموذج OPA365 سلوكي، ومثال دائري يعمل من الهاتف. اجتازت اختبارات Python للمحركات والاتزان الطاقي وتقارب خطوة الزمن. ما زالت بوابات الإصدار النهائي غير مكتملة: لا يوجد بعد هدف معدني حجمي 3D موثق، ولا تربة، ولا تحقق SPICE/FEM كامل، ولا ADC/قياس حقيقي، ولا معايرة مختبرية أو توقيع إصدار ثابت أو اختبار نهائي على هاتف فعلي.
- الخطوة التالية: تثبيت نجاح بناء Android واختباراته، ثم مقارنة شبكة RX/AFE مع SPICE، وإضافة نموذج المضخم/ADC التفصيلي ونوافذ أخذ العينات، ثم توسيع الهدف إلى توزيع تيارات دوامية ثلاثي الأبعاد.
- تم إيقاف النشر التلقائي لإصدارات GitHub حتى اجتياز بوابات الإصدار النهائي. ملفات CI الحالية تحفظ كـ Artifacts مرشحة فقط.
- وُجد إصدار سابق بالوسم `islam-lab-v1.0.0` أنشأته آلية النشر القديمة ووقّع بمفتاح Debug مؤقت؛ لا يُعتمد كإصدار نهائي ولا كهوية توقيع للتحديثات.
- هذا المستند معيار قبول، وليس ادعاءً بأن هذه الوظائف قد اكتملت.
