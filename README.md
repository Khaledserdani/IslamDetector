# Islam Detector — Android companion app

نسخة Android تجريبية للتواصل مع لوحة ESP32-S3 الخاصة بجهاز PI.

## الوظائف الموجودة
- واجهة عربية من اليمين إلى اليسار.
- حفظ القياسات محلياً في SQLite حتى بعد إغلاق التطبيق.
- قراءة حالة الجهاز دورياً عبر Wi-Fi من المسار `GET /status`.
- عرض الإشارة والثقة والعمق وحالة المعايرة عند إرسالها من المتحكم.
- إرسال أوامر التحكم وتصدير سجل القياسات بصيغة CSV.

## بروتوكول ESP32 المطلوب
اتصل الهاتف بنقطة Wi-Fi التي ينشئها ESP32، ثم افتح التطبيق. العنوان الافتراضي هو `192.168.4.1`.

### حالة الجهاز
`GET /status` يجب أن يعيد JSON، مثال:
```json
{
  "device": "Islam Detector",
  "state": "detecting",
  "signal": 128.4,
  "confidence": 72.0,
  "depth_cm": null,
  "calibrated": true,
  "calibration_percent": 100
}
```
الحقول الرقمية اختيارية؛ لا تعرض الواجهة قيمة غير مرسلة. يمكن وضع القيم داخل كائن `data`.

### أوامر التحكم
`POST /control` مع ترويسة `Content-Type: application/json`:
```json
{"command":"start"}
```
القيم المدعومة: `start`, `stop`, `calibrate`.
يرد ESP32 برمز HTTP من فئة 2xx وجسم JSON مثل:
```json
{"ok":true,"command":"start"}
```

## حدود النسخة الحالية
- التطبيق لا يعتبر قراءة الإشارة أو العمق حقيقة إلا إذا أرسلها ESP32 بعد تنفيذ دائرة القياس والمعالجة والتحقق الميداني.
- نسبة الثقة والعمق المعروضان مصدرهما المتحكم؛ التطبيق لا يخترع تصنيفاً للمعدن.
- لا يحتوي هذا المستودع بعد على Firmware نهائي للوحة ESP32، ولا يمكن تأكيد أداء الكشف دون اختبارات فعلية بالملف DD.

## البناء
يتطلب Java 17 وAndroid SDK وGradle 8.9. يشغّل GitHub Actions `clean assembleDebug` ثم يفحص سلامة APK وحجمه قبل رفعه.
