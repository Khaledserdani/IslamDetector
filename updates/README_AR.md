# قناة تحديثات ISLAM LAB

ملف القناة النشطة هو `channel.json` في هذا المجلد، ويقرأه التطبيق عبر HTTPS.

عند تجهيز إصدار جديد:
1. ارفع APK إصدار **Release موقّعاً** بمفتاح التوقيع نفسه المستخدم للإصدار المثبّت.
2. ارفع APK إلى صفحة GitHub Release.
3. احسب بصمة SHA-256 للملف المنشور نفسه.
4. حدّث `channel.json` بقيم `versionCode` الأعلى، و`versionName`، ورابط HTTPS المباشر، وبصمة SHA-256 من 64 خانة، وملاحظات الإصدار.
5. اختبر التحديث على نسخة مثبتة سابقة قبل إعلان الإصدار.

مثال لبنية القناة:

```json
{
  "channel": "stable",
  "versionCode": 2,
  "versionName": "0.2.0",
  "apkUrl": "https://github.com/OWNER/REPO/releases/download/TAG/islam-lab.apk",
  "sha256": "ضع_هنا_64_رمزاً_من_بصمة_SHA256",
  "releaseNotes": "وصف التحديث"
}
```

**الأمان:** التطبيق لا يثبت بصمت. يتحقق من SHA-256 ثم يفتح مثبت أندرويد، الذي يتحقق بدوره من توقيع الحزمة ويطلب موافقة المستخدم. إذا اختلف مفتاح التوقيع أو كان `versionCode` غير أعلى، سيرفض أندرويد التحديث. لا تضع مفاتيح التوقيع أو كلمات المرور في هذا الملف أو داخل المستودع.

القناة الحالية متروكة على `versionCode: 0` عمداً إلى أن يتوفر إصدار Release موقّع صالح للتحديث؛ لذلك لن يعرض التطبيق تحديثاً وهمياً.
