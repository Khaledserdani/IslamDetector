# محرك RX والحماية AFE — ISLAM LAB

## الهدف
يأخذ المحرك القوة الدافعة المستحثة المفتوحة من خرج محرك نبضة PI، ثم يحسب ما يحدث عند تحميل ملف RX بدائرته الحقيقية المختزلة: مقاومة ومحاثة الملف، مقاومة التخميد المتوازية، TVS على طرف الملف، مقاومة الحماية المتسلسلة، سعة مدخل الاستقبال، مقاومة انحياز المدخل، ومحدد Schottky ثنائي الاتجاه عند مدخل AFE.

## طوبولوجيا النموذج
1. مصدر ثيفينن (e_{RX}(t)) يمثل مجموع القوة الدافعة المستحثة من TX والهدف.
2. مقاومة ومحاثة ملف RX على التوالي.
3. على عقدة الملف: مقاومة تخميد (R_d) بالتوازي مع TVS ثنائي الاتجاه اختياري.
4. مقاومة حماية متسلسلة (R_s) تصل إلى عقدة مدخل AFE.
5. عند المدخل: (C_{in}) و(R_{bias}) ومحدد ثنائي الاتجاه إلى مرجع الإشارة المحلي.

يُحل جهد عقدة الملف من KCL مع TVS غير الخطي، ثم تُحل معادلتان تفاضليتان لحالة تيار ملف RX وجهد مدخل AFE. يدمج RK4 القدرة في مراحل كل خطوة ويحسب طاقة المصدر، فقد النحاس، التخميد، TVS، مقاومة السلسلة، مقاومة الانحياز، ومحدد المدخل. يجب أن يغلق اتزان الطاقة ضمن حد الاختبار.

## نموذج المضخم OPA365
بعد شبكة الحماية، يضيف المحرك نموذجاً سلوكياً من الدرجة الأولى للمضخم غير العاكس: كسب مغلق قابل للتغيير، مرجع انحياز، عرض نطاق تقريبي (GBW/A_v)، حد معدل تغير الخرج، وقص عند قضبان التغذية مع هامش الخرج. إعداد العينة يستخدم 3.3 V، مرجع 1.65 V، وكسب 2.0.

قيم TI النموذجية: GBW=50 MHz وSR=25 V/µs عند تغذية 5 V، ومجال تغذية 2.2–5.5 V، ومدخل rail-to-rail يمتد 100 mV وراء القضبان. هامش الخرج 10 mV هو قيمة نموذجية عند تغذية 5.5 V وحمل 10 kΩ. إعدادنا 3.3 V يستخدم هذه القيم كحدود سلوكية مرجعية لا كضمان أداء عند كل تغذية أو حمل. ورقة البيانات: https://www.ti.com/lit/ds/symlink/opa365.pdf

## إعداد العينة
ملف `sample_afe_config.json` يضع:
- RX: (R=4.8\ \Omega)، (L=750\ \mu H). المقاومة متوافقة تقريبياً مع حساب سلك RX المعتمد (4.802 Ω عند 20°C)، والمحاثة قيمة مرجعية ضمن المجال التصميمي وليست قياساً.
- تخميد متوازٍ: 390 Ω.
- مقاومة حماية متسلسلة: 1 kΩ.
- سعة مدخل إجمالية مفترضة: 2 nF.
- مقاومة انحياز: 1 MΩ إلى مرجع الإشارة المحلي (يمثل المرجع كصفر في معادلات الإشارة التفاضلية).
- TVS الملف: عتبة نموذجية افتراضية 6 V ومقاومة ديناميكية 2 Ω.
- محدد المدخل: عتبة افتراضية ±0.35 V حول مرجع الإشارة المحلي ومقاومة ديناميكية 50 Ω.
- OPA365 سلوكي: كسب 2، تغذية 0–3.3 V، مرجع 1.65 V، GBW=50 MHz، slew=25 V/µs، وهامش خرج 10 mV.

**قيم TVS والمحدد والسعة والانحياز افتراضات للمقارنة الحسابية، وليست مواصفات مؤكدة لقطعة SMAJ5.0CA أو BAT54S أو OPA365.** لا تعتمد منها قيمة مكوّن للشراء أو التصنيع قبل إدخال منحنيات datasheet الفعلية وطوبولوجيا الدائرة ومصدر تغذية المضخم.

```bash
python -m unittest -v test_afe_engine.py
python pulse_engine.py sample_pulse_config.json --output-dir pulse-engine-output
python afe_engine.py pulse-engine-output/pulse_waveform.csv sample_afe_config.json --output-dir afe-output

```

تُنفذ CI محرك النبضة أولاً، ثم تمرر موجة RX الناتجة إلى AFE وتؤرشف الموجتين والتقرير في أثر واحد.



## تحقق مستقل مع ngspice 42
أضيف `afe_spice_crosscheck.py` لتوليد netlist من موجة RX نفسها ومقارنة محرك Python مع ngspice على الشبكة الخطية فقط. يوقف الاختبار TVS الملف ومحدد المدخل ويقارن Rcoil/Lcoil/Rdamp/Rseries/Cin/Rbias. تُستخدم `UIC` مع تيار ابتدائي صفر للمحث وجهد ابتدائي صفر للمكثف حتى تتطابق شروط البداية مع حل Python.

تشغيل:
```bash
sudo apt-get install -y ngspice
python afe_spice_crosscheck.py pulse-engine-output/pulse_waveform.csv sample_afe_config.json --output-dir spice-crosscheck
```

نتيجة CI رقم `43431509091`:
- أقصى خطأ نسبي لجهد طرف RX: (9.5676\times10^{-6}) = 0.0009568%.
- أقصى خطأ نسبي لجهد مدخل AFE: (2.3317\times10^{-7}) = 0.0000233%.
- أقصى خطأ نسبي لتيار ملف RX: (1.2749\times10^{-5}) = 0.0012749%.
- نجحت المقارنة ضمن حد القبول المسبق 1.5%، باستخدام ngspice 42.
- أثر النتائج: `ISLAM-LAB-PI-pulse-engine-reference` رقم `14040177215`، ويتضمن موجة Python وموجة ngspice وملف المقارنة وJSON metrics.

هذه مطابقة مستقلة قوية للشبكة الخطية RLC وشروط البداية فقط. لا تختبر TVS/Schottky غير الخطية ولا OPA365؛ هذان لا يزالان نموذجين سلوكيين/قطعيين يحتاجان منحنيات قطع فعلية ومقارنة منفصلة مع SPICE.

## الحدود الحالية
- هذا نموذج lumped من الدرجة المختزلة، وليس محاكاة SPICE للدارة أو نموذجاً ترانزستورياً للمضخم.
- TVS والمحدد ممثلان بعتبة ومقاومة ديناميكية ثابتتين، لا بمنحنيات I-V/حرارة/زمن استجابة حقيقية.
- نموذج OPA365 الحالي سلوكي أحادي القطب مع GBW ومعدل تغير وحدود قضبان؛ ليس نموذجاً ترانزستورياً من TI ولا يحاكي تعويض الاستقرار، تيار الخرج، الأحمال السعوية أو الاسترداد التفصيلي من التشبع.
- لا توجد بعد سعة PCB والأسلاك، ESL/ESR، diode recovery، شبكة feedback الفعلية، common-mode عند كل لحظة، أو ADC.
- مرجع المحدد ثنائي الاتجاه محلي؛ لا يمثل بعد شبكة قضبان تغذية أحادية 0–3.3 V بدقة.
- لا توجد ضوضاء حرارية أو EMI أو تربة في هذا المحرك.
- موجة الدخل نفسها من هندسة حلقات العينة الاصطناعية وليست DD32 المقاس.

## الخطوة التالية
إضافة شبكة feedback الفعلية وتحليل استقرار المضخم، ثم ADC ونوافذ أخذ العينات والضوضاء، والتحقق المتقاطع مع SPICE. بعد ذلك تتم مقارنة شبكة الاستقبال في ngspice أو SPICE موثوق، وإدخال منحنيات قطع فعلية قبل اعتماد التصميم.
