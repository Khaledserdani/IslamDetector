# محرك نبضة PI المقترنة — ISLAM LAB

## ما يحسبه
يحل المحرك معادلات دائرة TX المقترنة بحلقة تيار دوامي مكافئة واحدة داخل الهدف:

`L_TX dI_TX/dt + M_TX,T dI_T/dt + R_TX I_TX = V_drive - V_clamp`

`M_TX,T dI_TX/dt + L_T dI_T/dt + R_T I_T = 0`

خلال تشغيل المفتاح يكون `V_drive = V_bus` و`V_clamp=0`. بعد الإطفاء يصبح المصدر صفراً، ويطبق المحرك جهداً معاكساً للتيار بقيمة clamp المدخلة. عندما تكون قيمة clamp صفراً يكون الإطفاء الطبيعي عبر مقاومة الملف هو الحالة الرياضية المستخدمة للمقارنة.

جهد RX مفتوح الدائرة يُحسب من:
`V_RX = -M_TX,RX dI_TX/dt - M_RX,T dI_T/dt`

ويُعرض مركب TX المباشر ومركب الهدف كلٌّ على حدة. الاقترانات الموقعة تُستخرج من مسارات الأسلاك ثلاثية الأبعاد بواسطة تكامل Neumann، مع عدد اللفات المدخل.

## فحص الطاقة
تُحسب طاقة المصدر وفواقد النحاس TX والهدف والطاقة الممتصة في عنصر التثبيت وتغير الطاقة المغناطيسية بتكامل RK4 على مراحل كل خطوة. يخرج المحرك خطأ اتزان الطاقة النسبي. هذا فحص اتساق داخلي، لا إثبات صحة تمثيل الهدف الحقيقي.

## صيغة ملف JSON
الملف المطلوب للتطبيق يحتوي:
- `paths_m.TX`, `paths_m.RX`, `paths_m.target_loop`: مسار مركز السلك المغلق لكل لفة، بالمتر، بنقاط X/Y/Z.
- `turns`: عدد لفات TX وRX وحلقة الهدف.
- `electrical`: مقاومة TX المقاسة أو المعلنة بوضوح، ومحاثة TX وRX.
- `target`: مقاومة ومحاثة الحلقة المكافئة للهدف.
- `pulse`: جهد المقارنة، عرض النبضة، جهد التثبيت، خطوة الزمن، ونهاية المحاكاة.

الملف `sample_pulse_config.json` مثال اصطناعي لاختبار سير العمل فقط. الحلقات الدائرية فيه **ليست هندسة DD32** ولا تمثل هدفاً معدنياً مقاساً.

## الاختبارات
تشمل:
- مقارنة ارتفاع وانطفاء TX بالحل المغلق لدائرة RL عندما يكون اقتران الهدف مهملاً.
- فصل مركب RX المباشر عن مركب الهدف.
- اتزان الطاقة مع الإطفاء الطبيعي ومع جهد تثبيت.
- تقارب الموجة عند تنصيف خطوة الزمن.
- خطية التيار مع جهد التغذية.
- رفض مصفوفة محاثة غير موجبة التعريف.

## حدود النموذج الحالي
- حلقة واحدة مكافئة للتيارات الدوامية؛ الأجسام الصلبة تحتاج شبكة حلقات أو FEM حجمي/محوري للتحقق من توزيع التيار.
- RX مفتوح الدائرة؛ لا يوجد بعد حمل AFE أو حماية clamp أو سعة الإدخال أو الضوضاء.
- لا توجد تربة أو نفاذية مغناطيسية متغيرة أو تشبع أو حرارة.
- مصدر الجهد والمفتاح والتثبيت عناصر مثالية؛ لا يوجد نموذج MOSFET أو gate driver أو parasitics.
- لا تستنتج النتائج عمق كشف أو نسبة نجاح ميداني.
- يجب إدخال هندسة CAD/قياسات حقيقية وR/L المقاسة قبل استخدام النتائج لاتخاذ قرار تصنيع.
