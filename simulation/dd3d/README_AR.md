# محرك المجال ثلاثي الأبعاد DD — النواة المرجعية

## الهدف
طبقة حساب مستقلة عن نموذج Elmer المحوري الحالي. تستقبل مسارات TX وRX ثلاثية الأبعاد من CAD أو من هندسة ملف مقاسة، وتحسب المجال المغناطيسي بقانون Biot–Savart والمحاثة المتبادلة الموقعة بتكامل Neumann.

## لماذا هذه الخطوة
ملف DD32 ذو جناحين، وليس ملفاً دائرياً محورياً. نموذج Elmer الحالي مفيد كمرجع محوري مستقل، لكنه لا يصف جناحي DD أو منطقة التداخل. هذه النواة لا تستبدل Elmer؛ إنها طبقة تحقق هندسي أولى قبل بناء نموذج FEM ثلاثي الأبعاد.

## صيغة الهندسة
ملف JSON يتضمن:
- paths_m.TX وpaths_m.RX: رؤوس مسار لفة واحدة بإحداثيات X/Y/Z بالمتر.
- turns.TX وturns.RX: عدد اللفات المعتمد.
- observation_points_m: نقاط حساب المجال.
- tx_current_a: تيار المقارنة.

يجب أن يكون كل مسار مغلقاً. اتجاه ترتيب النقاط يحدد القطبية. يمكن إضافة `wire_lengths_m.TX` و`wire_lengths_m.RX` إلى JSON لمقارنة طول مسار اللفة الواحدة بمتوسط طول السلك الفعلي لكل لفة؛ هذا تدقيق اتساق هندسي، وليس إثباتاً لتوزيع اللفات أو شكل الحزمة.

## الاختبار والتشغيل
من هذا المجلد:
```bash
python3 -m unittest -v test_filament_model.py
python3 run_dd3d_reference.py dd32_geometry.json --output dd32_reference.json
```

يقارن الاختبار مجال الحلقة الدائرية العددي بالحل التحليلي على محورها، ويفحص تقارب الخطأ، وخطية المجال مع التيار واللفات، وتماثل المحاثة المتبادلة، وانعكاس القطبية.

## القيود العلمية
- الأسلاك خطوط مركزية رفيعة؛ لا يوجد نموذج لمقطع النحاس أو توزيع التيار داخله.
- التكامل العددي بنقاط منتصف المقاطع؛ يجب اختبار التقارب لكل هندسة فعلية.
- لا يوجد بعد هدف موصل أو تربة أو نبضة زمنية أو دائرة TX أو AFE أو ضوضاء.
- لا تستخرج هذه النواة عمق كشف أو SNR أو احتمال كشف.
- لا تسمى الهندسة DD32 قبل تصدير مسارات اللف الفعلية بعد تثبيت القالب وقياس التداخل والارتفاع والفصل.

## بوابة الانتقال
1. توفير مسارات TX/RX من CAD أو قياسات قالب DD32.
2. إثبات تقارب المجال والمحاثة المتبادلة بزيادة عدد مقاطع المسار.
3. مقارنة هندسة بسيطة مع حل FEM مستقل.
4. ثم إضافة هدف موصل وزمن متغير، فالتربة، فدائرة الاستقبال.


## مراجع نماذج الشركات للمرحلة التالية — 13 نوفمبر 2026
تم التحقق من وجود مصادر النماذج الرسمية التالية، وهي مصادر عمل وليست نتائج محاكاة معتمدة بعد:
- **BAT54S — Diodes Incorporated:** صفحة المنتج الرسمية توفر SPICE model، وورقة البيانات تحدد حدود VF والسعة وزمن الاسترداد. https://www.diodes.com/part/view/BAT54S
- **SMAJ5.0CA — STMicroelectronics:** صفحة المنتج الرسمية تعرض نماذج SPICE حرارية كهربائية لسلسلة SMAJ بصيغ LTspice وPSpice وغيرها. لم يُدمج ملف النموذج بعد. https://www.st.com/en/protections-and-emi-filters/smaj5-0ca.html
- **OPA365 — Texas Instruments:** صفحة المنتج الرسمية تعرض PSpice Model Rev. A (SBOC133A.ZIP) ومرجع TINA-TI. لم يُدمج النموذج في محرك AFE بعد. https://www.ti.com/product/OPA365

### ترتيب التحقق المطلوب
1. فحص ملفات الشركات والترخيص والصيغة، ثم اختبار توافقها مع ngspice قبل اعتمادها.
2. بناء testbench transient لزوج BAT54S مع سعات الوصلات والسكك الفعلية.
3. بناء testbench حراري/كهربائي لـ SMAJ5.0CA مع شكل النبضة وحرارة البداية والطفيليات، وعدم الاكتفاء بخط endpoint.
4. استبدال OPA365 السلوكي بنموذج TI بعد فحص صيغة PSpice، ثم توصيل شبكة feedback الفعلية واستخراج loop gain/phase margin والاستجابة الزمنية.
5. ربط خرج المضخم بنموذج ADC ونوافذ الاستحواذ.

لا تُعتمد قيم الحماية أو الكسب أو عمق الكشف من هذه المصادر وحدها؛ يلزم تطابق طوبولوجيا الدارة الفعلية وظروفها وقياسها.


## تصحيح رابط ST وتدقيق BAT54S الرسمي — 13 نوفمبر 2026
- رابط ST الصحيح للأرشيف الحراري PSpice هو `https://www.st.com/resource/en/spice_model/smaj-series-thermal-pspice.zip`، كما يظهر مباشرة في صفحة موارد SMAJ5.0CA. رابط LTspice منفصل.
- تم فتح ملف BAT54S SPICE الرسمي وقراءة تعريف النموذج `DI_BAT54S`: `IS=34.9u`, `RS=0.210`, `BV=30.0`, `CJO=13.3p`, `M=0.333`, `N=2.28`, `TT=7.20n`. يجب اختبار هذا النموذج في دائرة المشبك الثنائية كاملة؛ لا تستبدل جدول I-V الحالي قبل مطابقة الطوبولوجيا وظروف الانحياز.
- TI OPA365 PSpice Model Rev.A متاح رسمياً باسم `SBOC133A.ZIP`. الخطوة المطلوبة فحص archive/subcircuit/pin order والتوافق، ثم feedback transient وloop stability.


## تحقق الفيض السطحي المستقل — إضافة أولية
أضيفت دالتا `flux_through_loop` و`flux_linkage` لحساب تدفق مجال مصدر ثلاثي الأبعاد عبر سطح حلقة استقبال مستوية ومحدبة، بتقسيم مثلثات السطح وتقييم مجال Biot–Savart عند مراكز المثلثات. ترفض الخوارزمية السطح غير المستوي أو المقعر أو المتدهور، وتضع حداً لحجم شبكة التكامل.
- يقارن الاختبار `N_RX·Φ/I_TX` مع محاثة Neumann لنموذج حلقتين دائريتين مرجعيتين، مع درجات تقسيم 8 و16 و32، ويتطلب تحسن الخطأ وتقاربه إلى أقل من 0.01%.
- هذا مسار تحقق مستقل أولي وليس حلاً تحليلياً عاماً لكل شكل؛ يلزم إجراء تقارب لكل هندسة فعلية.
- لا يمثل الاختبار DD32 ولا يحدد تداخل جناحيه؛ مساراته الحقيقية ما زالت مطلوبة من CAD أو القياس.
