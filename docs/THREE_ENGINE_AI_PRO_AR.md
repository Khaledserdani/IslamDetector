# ISLAM DETECTOR AI PRO — قرار وبنية الجيل الثالث
التاريخ: 2026-11-09
الفرع: feature/three-engine-ai-pro

## قرار المستخدم المعتمد
إنشاء تطبيق Android ثالث مستقل عن Islam Detector وIslam Detector Pro، بثلاثة محركات:
1. المحرك الفيزيائي/الرياضي: معالجة بيانات PI الخام متعددة النوافذ، خط الأساس، الضجيج، الاستقرار، خصائص الاضمحلال وتأثير التربة.
2. محرك الذكاء الاصطناعي المحلي LiteRT: تشغيل نموذج مدرب محلياً على Android بعد جمع بيانات موسومة واختباره.
3. محرك المقارنة والتحكيم: مقارنة مخرجات المحركين وجودة البيانات والمعايرة، وإصدار نتيجة نهائية أو "غير حاسم" عند نقص الأدلة أو اختلاف النتائج.

## واجهة النتائج
ثلاثة إطارات منفصلة: نتيجة المحرك الفيزيائي، نتيجة LiteRT، ونتيجة التحكيم النهائي، مع عرض الاحتمال فقط عندما يكون محسوباً ومُعايراً ومختبراً. تأكيد المستخدم بعد تحقق ميداني: هدف مؤكد / لا يوجد هدف / غير حاسم. تُحفظ العينة والتأكيد لمراجعة لاحقة، ولا يُعدّل النموذج مباشرة بعد كل ضغطة.

## العمق
يعرض التطبيق العمق الذي يرسله ESP32 مع توضيح مصدره، أو يتركه غير متاح. تقدير عمق موثوق يحتاج قياسات PI خام متعددة النوافذ، معايرة بأهداف معلومة العمق والحجم والمادة، وظروف تربة مختلفة، واختباراً مستقلاً. لا يجوز اشتقاق العمق من شدة إشارة منفردة أو اختراع رقم.

هذا أول هيكل قابل للبناء للواجهة الثلاثية، وليس محركاً علمياً مكتمل الأداء. محرك LiteRT والنموذج المدرب غير مدمجين في هذه المرحلة. الحساب الفيزيائي الحالي مؤشر وصفي أولي لتغير النوافذ وليس تصنيف معدن أو احتمال هدف. لا يدّعي التطبيق تقدير عمق مستقل. يلزم توسيع البروتوكول وجمع بيانات PI حقيقية والتحقق الميداني.
