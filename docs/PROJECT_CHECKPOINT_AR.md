## 3. معمارية القياس Rev A

التقسيم المرشح:
- ESP32-S3-N16R8: Wi-Fi وWebServer وإدارة الهاتف والتخزين.
- RP2040-Zero: مرشح لمحرك التوقيت والاكتساب باستخدام PWM/PIO/DMA.
- ADS8861: ADC مرشح 16-bit/1MSPS لمسار RX التفاضلي في سيناريو DD.
- THS4521: مضخم تفاضلي مرشح لمسار RX التفاضلي.
- ADR4540B: مرجع DC خام مرشح؛ لا يكفي وحده كسائق REF للـADC ويحتاج سائقاً فعالاً.
- ADS8860 وADS7054 وبدائل أخرى تبقى للمقارنة إذا تغيرت هندسة RX أو أثبت التوفر/القياس أنها أفضل.

**لا يوجد اختيار ADC أو مضخم أو حماية نهائي للمنتج حتى الآن.** Rev A الحالي لا يفرض أن ملف البحث سيكون DD.

## 4. Firmware التوقيت الحالي

المسار:
- `firmware/rp2040_timing_test/`
- GP4: نبضة TX_TEST منطقية 3.3V، عرضها 20µs، بمعدل 100Hz.
- GP5/GP6: علامات اختبار/تشخيص.
- PIO اختياري لقراءة ADS8861: GP8=CONVST، GP9=SCLK، GP10=DOUT.
- النوافذ المرشحة: 8/12/16/24/36/52/72/100µs بعد هبوط GP4.
- الاستراتيجية الحالية: ثماني عينات داخل اضمحلال نبضة TX واحدة، وليس عينة واحدة عبر ثماني نبضات.
- SCLK المحسوب نحو9.615MHz، وCONVST HIGH=768ns، وأول SCLK بعد120ns من هبوط CONVST.
- `ENABLE_ADS8861_CAPTURE=0`؛ مسار ADC مدمج في البناء لكنه معطل افتراضياً حتى تركيب ADC والحماية والتغذية.

**تحذير:** GP4 خرج منطق 3.3V للاختبار فقط. ممنوع توصيله ببوابة MOSFET أو ملف أو دائرة 12V.

## 5. بروتوكول البيانات

الوثيقة:
- `docs/engineering/REV_A_DATA_PROTOCOL_AR.md`

الإطار الحالي:
- إطار MEASUREMENT واحد لكل نبضة TX، ويحتوي حتى 8 عينات 16-bit من النوافذ الزمنية داخل النبضة نفسها.
- حجم الإطار الكامل عند 8 عينات يقارب49 بايت.
- UART TTL 3.3V، السرعة المقترحة 921600 baud، 8N1.
- عند 1000 نبضة/ثانية ينتج تقريباً49kB/s قبل رسائل التحكم، أي نحو53% من السعة النظرية لـ921600 baud.
- CRC16، sequence، timestamp، valid mask، وDEVICE_INFO لتحديد نموذج ADC وصيغة العينة.

هذا عقد بيانات ومرجع Python؛ لم يثبت بعد UART Hardware Loopback أو تكامل Firmware RP2040 مع ESP32-S3.

## 6. حالة ملف البحث — غير محسوم نهائياً

**لا يوجد شكل أو قطر أو عدد لفات أو قطر سلك أو محاثة نهائية معتمدة.** DD32 ليس قراراً نهائياً ولا مواصفة شراء.

التصاميم المفتوحة للمقارنة:
- Mono بملف واحد TX/RX.
- TX/RX دائريان منفصلان.
- DD.
- TX مستقل مع زوج RX متناظر تفاضلي.
- Figure‑8 / gradiometer.
- هندسات هجينة أخرى إذا أثبتت فائدتها.

أضيفت دراسة المقارنة:
- `docs/engineering/COIL_TOPOLOGY_STUDY_AR.md`

التوصية لمنهج النموذج فقط: TX مستقل قابل للتبديل، مع مقارنة RX دائري مستقل، وزوج RX متناظر، وDD؛ ويظل Mono مرجعاً بسيطاً. هذه ليست مواصفة إنتاج.

تحسينات استقبال قيد الدراسة:
- Time-Domain Bucking قبل الكسب العالي لتقليل الإشارة المباشرة والتشبع.
- Switched-segment RX لتقليل المحاثة أثناء ارتداد TX ثم إعادة التوصيل؛ فكرة عالية التعقيد ولا تطبق قبل قياس الحاجة والجهود العابرة.

## 8. ما لم يثبت بعد

- لا توجد قياسات فعلية لملف بحث مختار؛ لم يُحسم الملف.
- لا يوجد اختبار timing jitter فعلي على RP2040-Zero براسم/محلل منطقي.
- لا يوجد اختبار Hardware للـADS8861 أو THS4521 أو مرجع ADC.
- لا توجد قيم حماية RX أو gain أو damping نهائية.
- لا يوجد مخطط KiCad أو PCB/PCBA نهائي.
- لا يوجد اختبار قدرة TX بملف بحث؛ لا تبدأ مرحلة القدرة قبل حساب الارتداد والطاقة والحماية.
- لا يوجد اتصال UART مثبت بين RP2040 وESP32-S3.
- لا يوجد اتصال مثبت بين التطبيق واللوحة الحقيقية.
- لا يوجد قياس ميداني موثق لعمق أو تصنيف أو دقة.

## 9. خطوات الاستكمال بالترتيب

1. تدقيق PIO/ADS8861 مقابل ورقة TI ومراجعة توقيت GP4→CONVST→SCLK→DOUT.
2. اختبار RP2040-Zero رقمياً دون أي مرحلة قدرة، وتسجيل jitter والنوافذ الفعلية.
3. اختبار واجهة RX/ADC منخفضة الإشارة دون TX، مع VREF وsettling والضوضاء.
4. إكمال مقارنة هندسات الملف وتحديد المرشح الأفضل بالقياس، لا بالافتراض.
5. إعادة تصميم حماية RX والتضخيم والمرجع حسب الملف الفائز.
6. حساب مرحلة TX والطاقة والارتداد واختبارها بحمل بديل محدود التيار.
7. اختبار TX/RX المتكامل ثم UART مع ESP32-S3.
8. ربط التطبيق بالقياسات الحقيقية، ثم الاختبارات الميدانية والتربة وقاعدة بيانات التعلم.
9. بعد اجتياز بوابات الاختبار فقط: KiCad وBOM وPCB/PCBA والنسخة الإنتاجية.

## 10. قاعدة السلامة والتوثيق

- لا توصل GP4 ببوابة MOSFET أو ملف البحث.
- لا توصل 12V إلى RX أو ADC أو RP2040.
- لا تختبر مرحلة TX دون مزود محدود التيار ومسبار مناسب لقياس عقد الجهد العابرة.
- لا تستخدم مشبك أرضي راسم عادي على عقدة تبديل عائمة.
- كل قيمة تصنف: من ورقة بيانات، محسوبة، مقاسة على الطاولة، أو مثبتة ميدانياً.
- لا تعلن نجاح اختبار أو عمق أو دقة دون سجل قابل للتحقق.
