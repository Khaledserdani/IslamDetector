# مسح حسابي لخيارات نبضة TX — DD32
**المراجعة:** A — 2026-11-12  
**الحالة:** أداة حسابية أُضيفت إلى CI؛ نتائج الأثر بعد التشغيل الجديد.

## الغرض
تكوين جدول مقارنة شفاف يربط جهد المصدر الافتراضي ومحاثة الملف وعرض النبضة بتيار الذروة والطاقة المغناطيسية المثالية. الهدف تضييق مساحة التصميم قبل اختبار مرحلة القدرة، وليس اعتماد مصدر أو تيار تشغيل.

## مدخلات المسح
- المقاومة: 1.52 Ω، تقدير نظري لموصل TX عند 20°C، وليست قراءة ملتيميتر.
- المحاثة: 300 و350 و400 µH، ضمن المجال المستهدف لاختبار TX.
- جهد المقارنة: 5 و12 V؛ قيم افتراضية للمقارنة فقط.
- عرض النبضة: 50 و100 و200 µs.
- عدد الحالات: 18 حالة.

## النموذج
`tau=L/R`
`Ipeak=(V/R)*(1-exp(-Ton/tau))`
`E=0.5*L*Ipeak^2`

الأداة `simulation/ngspice/generate_tx_rl_design_sweep.py` تنشئ CSV وتتحقق من أن التيار يرتفع مع زيادة عرض النبضة لكل مجموعة مدخلات.

## حدود النموذج
لا يتضمن المسح MOSFET أو مقاومة تشغيله أو Driver أو مكثف خزان أو مقاومة المصدر والأسلاك أو clamp أو استرجاع الطاقة أو التغير الحراري أو اقتران RX. لذلك لا تستخدم قيمه لاختيار MOSFET/TVS/Fuse أو لتحديد تيار التشغيل. جهد 12 V ليس قراراً معتمداً.

## ما يلزم قبل التصميم النهائي
1. قياس DCR وL للملف بعد تركيبه.
2. تثبيت مصدر TX محدود التيار وقياس هبوطه تحت الحمل.
3. تحديد حدود الحرارة ومعدل التكرار.
4. حساب مسار طاقة الإطفاء والجهد العابر، ثم اختيار القطع من Datasheet.
5. اختبار أولي محدود الطاقة مع مسبار تفاضلي وقياس تيار معزول.
