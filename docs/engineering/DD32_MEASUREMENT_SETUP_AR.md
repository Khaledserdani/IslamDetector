# تجهيز قياسات ملف DD32 — قائمة معدات وإجراء مختصر
**المراجعة:** A — 2026-11-12  
**الحالة:** خطة تجهيز للاختبار؛ لا تفترض امتلاك أدوات أو نتائج قياس.

## 1. أدوات القياس المطلوبة قبل اعتماد الملف
| الأداة | الاستخدام | الحد الأدنى العملي |
|---|---|---|
| ملتيميتر جيد | DCR وفحص الاستمرارية/العزل | مجال Ω مناسب ودقة معلومة؛ يفضل تعويض مقاومة المجسات |
| جهاز LCR | قياس L وRseries وQ | يدعم 100 Hz و1 kHz أو يسجل تردد الاختبار الفعلي |
| ميزان حرارة تلامسي | تصحيح مقاومة النحاس | تسجيل درجة حرارة الملف قرب اللف |
| راسم إشارة | مراقبة إشارة RX وزمن التعافي | عرض نطاق ومعدل عينة مناسبين للإشارة المقاسة |
| مسبار تفاضلي/قياس معزول | مراقبة عقدة عائمة أو جهد عابر | تصنيف جهد مشترك وتفاضلي مناسب للترتيب |
| مولد نبض/إشارة محدود الطاقة | اختبار اقتران منخفض الطاقة | خرج مضبوط مع مقاومة سلسلة وحد تيار معروف |

**أدوات اختيارية مفيدة:** قياس مقاومة أربع أسلاك Kelvin لملف TX المنخفض المقاومة، ومسبار تيار لقياس نبضة TX لاحقاً. لا يُعوّض غياب المسبار التفاضلي بتوصيل مشبك أرضي راسم مؤرض إلى نقطة عائمة.

## 2. ترتيب الاختبار الذي يمنع خلط النتائج
1. افصل TX وRX عن أي إلكترونيات، وافحص بصرياً المينا ومخارج الأسلاك.
2. سجل رقم الملف، اتجاه اللف، A/B، طول السلك الفعلي، عدد اللفات، مادة الحامل، ودرجة الحرارة.
3. قس DCR ثلاث مرات لكل ملف بعد تعويض مقاومة المجسات إن أمكن.
4. قس L وRseries وQ لكل ملف منفرداً، وسجل تردد القياس ومستوى الاختبار.
5. ضع الملفين في موضعهما الميكانيكي المقصود وسجل أبعاد التداخل والفصل.
6. قس الاقتران بطريقة aiding/opposing فقط إذا كانت طريقة التوصيل وأداة القياس واضحتين؛ وإلا سجّل إشارة RX الناتجة عن إثارة TX منخفضة الطاقة.
7. استخدم مولداً محدود الطاقة ومقاومة سلسلة، وراقب إشارة RX وزمن العودة إلى خط الأساس.
8. كرر DCR وL بعد تثبيت الملفين بالحامل وقبل إغلاق الغطاء.
9. احفظ القراءات الخام وصورة/رسم التوصيل وأداة القياس وإعداداتها؛ لا تستبدل القياس الأول بالقراءة الأخيرة.

## 3. شروط إيقاف الاختبار
- قراءة مقاومة متقطعة عند تحريك الكابل.
- تلف أو انكشاف المينا أو تماس الملف مع الحامل.
- ارتفاع غير متوقع في الحرارة.
- تجاوز جهد أو تيار الاختبار حدود الأداة أو الملف أو مصدر الإشارة.
- ظهور رنين أو جهد RX أعلى من مجال أداة القياس أو مدخلها.

عند ظهور أي حالة، افصل الإثارة وأصلح سببها قبل إعادة الاختبار. لا ترفع طاقة TX بغرض تحسين الإشارة قبل قياس DCR وL والاقتران والاستجابة منخفضة الطاقة.

## 4. البيانات التي تُسجل لكل قراءة
- معرف القياس، التاريخ والوقت، اسم الملف TX/RX.
- قيمة القراءة ووحدتها، التردد، مستوى الاختبار، ودرجة الحرارة.
- اسم الأداة والطراز ومجال القياس/المعايرة إن توفر.
- وضع الملف والاتجاه والمسافة/التداخل.
- طريقة توصيل A/B وأي مقاومة مجسات أو أسلاك إضافية.
- ملاحظة عن الاستقرار أو الضوضاء أو أي تكرار للقراءة.

## 5. ما بعد القياس
تستخدم النتائج الفعلية لتحديث نموذج الملف، ثم حساب تيار وطاقة النبضة واختيار Driver وMOSFET والحماية. لا تعتمد قيم عناصر مرحلة القدرة أو نافذة RX من هذه القائمة وحدها.
