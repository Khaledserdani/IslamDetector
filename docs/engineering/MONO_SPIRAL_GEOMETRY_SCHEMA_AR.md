# عقد تعريف هندسة Mono Spiral PI — 35×35 cm

**التاريخ:** 2026-11-20  
**الفرع المستهدف:** `feature/islam-lab-foundation`  
**الحالة:** عقد هندسي بارامتري؛ لا يحدد أبعاد تصنيع ولا يثبت عدداً للفات.

## 1. الغرض والحدود

يمنع هذا العقد حساب طول النحاس أو المحاثة من عبارة «35×35 cm» وحدها. المقاس الحالي هو غلاف اسمي مرجعي فقط. لا يعني تلقائياً أن خط مركز اللفة الخارجية يساوي 350×350 mm.

النطاق هو ملف Mono Spiral PI أحادي المسار، يعمل الموصل نفسه للإرسال والاستقبال بالتناوب. لا تنطبق عليه هندسة أو أرقام ملف DD32 أو مرشح 50/34 cm.

## 3. تعريف rounded-square كعائلة مرشحة، لا كقرار

إذا اختيرت عائلة المستطيل ذي الزوايا المدورة، تُعرّف كل لفة بخط مركز مستقل. للفة رقم k بدءاً من الصفر:

- العرض: `W_k = W_0 - 2 k p`
- الارتفاع: `H_k = H_0 - 2 k p`
- نصف قطر الزاوية: `r_k = r_0 - k p`

حيث p هي خطوة خط المركز. يجب رفض أي لفة تحقق:
- `W_k <= 0` أو `H_k <= 0`
- `r_k < 0`
- `2 r_k > min(W_k, H_k)`
- تداخل موصلين أو خرق مسافة العزل المحددة.

طول محيط خط مركز اللفة المدورة، قبل إضافة وصلات الانتقال والأطراف، هو:

`P_k = 2(W_k + H_k - 4 r_k) + 2 pi r_k`

وهذا يساوي مجموع المقاطع المستقيمة الأربعة وأقواس الزوايا الأربعة. لا يمثل طول الحلزون الكامل ما لم تُضف وصلات الانتقال وطرفا الخروج وفق مسار هندسي صريح.

## 4. تعريف الدائرة كعائلة مرشحة

إذا اختير مسار دائري متحد المركز، يجب تعريف نصف قطر خط مركز اللفة الأولى وخطوة المراكز. نصف قطر اللفة k:

`R_k = R_0 - k p`

وطول اللفة:

`P_k = 2 pi R_k`

يرفض التوليد إذا أصبح أي `R_k <= 0`. يجب أيضاً تعريف انتقالات الحلزون وطرفي الخروج؛ جمع المحيطات وحده لا يكفي لطول النحاس الكلي.

## 5. فحوص عامة إلزامية لأي عائلة

1. **استمرارية المسار:** مسار واحد مفتوح من طرف البداية إلى النهاية، دون فجوات أو تفرعات.
2. **عدم التقاطع:** لا يتقاطع خط المركز مع نفسه، ولا تتداخل أجسام السلك بعد توسيع المسار بنصف قطر السلك الخارجي.
3. **الخلوص:** المسافة الدنيا بين سطحي العزل المتجاورين لا تقل عن قيمة الخلوص التي يحددها تصميم العزل؛ لا تُخترع هذه القيمة.
4. **احتواء الغلاف:** كامل جسم السلك والحامل ضمن حدود الغلاف الميكانيكي، مع احتساب نصف قطر السلك ومساحة خروج الأطراف.
5. **قابلية اللف:** لا توجد انحناءات أو انتقالات أصغر من حد نصف قطر الثني الذي تسمح به مواصفات السلك.
6. **دقة التقسيم:** عند تصدير المسار إلى polyline، يعاد حساب الطول والمجال عند زيادة دقة التقسيم؛ تسجل نسبة التغير حتى يظهر التقارب.
7. **عدم مضاعفة اللفات:** إذا كان المسار المصدّر يحتوي كل اللفات فعلياً، يمرر إلى نواة المجال كمسار واحد مع معامل تراكب turns=1.

## 6. حساب طول النحاس والمقاومة

بعد اكتمال هندسة المسار:

`L_total = sum(P_k) + L_transitions + L_leads + L_service`

تُحسب المقاومة النظرية فقط بعد إدخال قطر النحاس العاري ودرجة الحرارة ومقاومية المادة:

`R(T) = rho(T) * L_total / (pi * copper_diameter^2 / 4)`

يجب فصل القيم حسب مصدرها:
- `GEOMETRY_CALCULATED`: طول مستنتج من مسار CAD.
- `ELECTRICAL_ESTIMATE`: مقاومة محسوبة من خواص النحاس.
- `MEASURED`: قراءة فعلية موثقة بأداة وطريقة ودرجة حرارة.

لا يجوز ترقية أي قيمة محسوبة إلى `MEASURED`.

## 7. بوابة المحاثة

لا تُستخرج المحاثة الذاتية من تكامل Neumann لسلك رفيع مع نفسه دون معالجة صحيحة للمقطع العرضي ونصف قطر الموصل وتوزيع التيار. يجب أن يذكر أي نموذج L:
- نموذج المقطع العرضي وتوزيع التيار؛
- التردد أو المجال الزمني ومستوى الإثارة؛
- معالجة الجزء الذاتي/المفرد؛
- مرجعاً تحليلياً مستقلاً واختبار تقارب؛
- مقارنة لاحقة بقياس LCR للملف الحقيقي.

اختبار تماثل مصفوفة الاقتران أو نجاح اختبارات وحدات وحده لا يثبت دقة L الذاتية.

## 9. قرار المرحلة

- مثبت: Mono Spiral PI أحادي، وغلاف اسمي 350×350 mm.
- غير مثبت: عائلة الشكل، أبعاد خط المركز، نصف قطر الزوايا/الدائرة، عدد اللفات، الخطوة، قطر النحاس والعزل، الانتقالات، الأطراف والارتفاع.
- ممنوع حالياً: إعلان طول سلك أو DCR أو L نهائية، أو استخدام قيم DD32/50-34 cm، أو اعتماد 13 لفة من اختلاف حسابين غير متقاربين.
- الخطوة التالية: تنفيذ مولد بارامتري يرفض المدخلات الناقصة، ثم اختبارات هندسة مستقلة لمسار تجريبي معلن بوضوح أنه اختبار برمجي وليس مواصفة الجهاز.
