# النموذج المرجعي لانطفاء تيار ملف TX في DD32
**المراجعة:** A — 2026-11-12  
**الحالة:** اجتاز نموذج ngspice CI على 2026-11-12.

## 1. المعلمات المستعملة ومصدرها
- مقاومة الملف: **1.52 Ω**، قيمة نظرية تقريبية لسلك نحاس مينا 0.60 mm بطول 25 m عند 20°C؛ القياس الفعلي للملف هو المرجع النهائي.
- محاثة الملف: **350 µH**، نقطة وسطية حسابية ضمن المجال المستهدف 300–400 µH، وليست قياساً.
- الإثارة: نبضة جهد **1 V** لمدة 200 µs، وهي قيمة تطبيعية لا تعني أن جهد TX الفعلي 1 V.
- القياس الأول: تيار الملف عند نهاية النبضة (200 µs).
- القياس الثاني: التيار بعد 300 µs إضافية (عند 500 µs).

## 2. الحل التحليلي
ثابت الزمن الاسمي:
`tau = L/R = 350 µH / 1.52 Ω = 230.263 µs`.

أثناء النبضة:
`i(t) = (V/R) × (1 - exp(-t/tau))`.

بعد انتهاء النبضة في دائرة RL المثالية:
`i(t) = i(Ton) × exp(-(t-Ton)/tau)`.

القيم المرجعية:
- `i(200 µs) = 0.381875 A` تقريباً.
- `i(500 µs) = 0.103776 A` تقريباً.
- `tau = 230.263 µs`.

## 4. حدود النموذج
هذا نموذج RL مثالي لملف TX فقط. لا يتضمن MOSFET أو Driver أو TVS أو مكثف الخزان أو مسار استرجاع الطاقة أو السعة الطفيلية أو ملف RX أو هدفاً معدنياً أو التربة. عند إضافة مسار clamp أو freewheel سيتغير شكل الانطفاء. لا تُستخدم نتائجه وحدها لاختيار نافذة blanking أو قيم حماية أو جهد/تيار النبضة النهائي.

الغرض الحالي هو التحقق من الحسابات الأساسية وربط مواصفات ملف DD32 الاسمية بنموذج زمني قابل لإعادة الإنتاج، ثم استبدال القيم الاسمية بقياسات DCR وL الفعلية.
