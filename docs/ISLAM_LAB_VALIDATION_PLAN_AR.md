# خطة التحقق العلمي لـ ISLAM LAB

## المرحلة 0 — منصة قابلة للبناء
- تطبيق Android مستقل.
- مولد إشارات اصطناعية واضح الوسم.
- عرض الموجة وعينات النوافذ.
- تصدير بيانات التجربة.
- اختبار بناء APK آلياً.

## المرحلة 1 — تحقق رياضي
- اختبارات وحدات لمعادلات كل نموذج.
- حالات حدية، وحدات، أبعاد، واستقرار عددي.
- مقارنة مع حلول مرجعية منشورة أو نتائج تحليلية معروفة.
- لا يكفي أن تبدو الرسوم منطقية.

## المرحلة 2 — محاكاة الدوائر
- تحديد محرك SPICE وإصداره.
- اختبارات transient وقيود نماذج المكونات.
- مقارنة عقد محددة بقياسات راسم إشارة حقيقي.
- تسجيل parasitics وESR/ESL وسلوك الحماية عند الحاجة.

## المرحلة 3 — محاكاة المجال والمواد
- تعريف هندسة الملف والهدف والوسط.
- تحديد خواص المواد ومصدرها واعتمادها على التردد/الحرارة عند الحاجة.
- فحص تقارب الشبكة العددية وحجم المجال والشروط الحدية.
- مقارنة حالات بسيطة ذات حلول مرجعية قبل الحالات المركبة.

## المرحلة 4 — ربط القياس الحقيقي
- اختيار جهاز قياس ذي نطاق وعرض حزمة ومعدل عينة مناسب.
- توثيق حدود المدخل والحماية والعزل والأرضي.
- مزامنة TX وRX وتوثيق التأخير.
- تخزين الموجات الخام قبل المعالجة.

## المرحلة 5 — معايرة النموذج والتوأم الرقمي
- معايرة على مجموعة تجارب معلومة.
- فصل مجموعة تحقق مستقلة لم تدخل المعايرة.
- الإبلاغ عن الخطأ ومجال الصلاحية وعدم اليقين.
- منع التعميم خارج نطاق المواد والهندسة والظروف المختبرة.

## بوابة السلامة
لا توصل ملفات أو دوائر قدرة بمداخل الهاتف أو USB مباشرة. استخدم واجهة قياس مصممة ومحمية ومناسبة للجهد والطاقة، ولا تجرّب نبضات TX عالية الطاقة قبل اعتماد الحماية والاختبار التدريجي.
