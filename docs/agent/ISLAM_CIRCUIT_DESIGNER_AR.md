# مصمّم الدوائر في ISLAM FREE AGENT

## الهدف
تحويل متطلبات الدارة إلى مواصفة منظمة قابلة للفحص، ثم إخراج:
1. مخطط SVG أولي برموز العناصر وتسميات العقد وأرقام الطرفين.
2. قائمة مكونات BOM بالكميات والقيم والتصنيفات التي قدمها المصمم.
3. ملف SPICE نصي مشتق من نفس المواصفة، لتجنب اختلاف الرسم عن قائمة التوصيل.
4. تقرير نطاق الدعم والافتراضات والبيانات الناقصة.

## خط المعالجة
`متطلبات المستخدم → مواصفة circuit spec → التحقق البنيوي والكهربائي → BOM + SVG + SPICE → المحاكاة المناسبة → مراجعة النتائج`

المخطط وملف SPICE وBOM كلها تُشتق من كائن المواصفة نفسه. لا يسمح للموديل بتمرير كود أو أوامر shell؛ أداة `design_circuit` ثابتة ومقيدة بسياسة السماح، والتنفيذ يتطلب موافقة بشرية صريحة.

## الإصدار الأول: Prototype
يدعم فقط المكونات ثنائية الطرف:
- مقاومة: R، قيمة بالأوم، تصنيف قدرة بالواط، وتفاوت.
- مكثف: C، قيمة بالفاراد، تصنيف جهد، وتفاوت.
- محث: L، قيمة بالهنري، تصنيف تيار، وتفاوت.
- مصدر جهد مستمر مثالي: V، قيمة بالفولت.

كل عنصر يملك طرفين ثابتين `1` و`2`، وتُعرّف الشبكات بأسماء عقد. اتصال طرفين يعني تطابق اسم العقد حرفياً. تُرفض مراجع العناصر المكررة، والوحدات غير المطابقة، والقيم غير المحدودة أو خارج المجال، والتصنيفات الناقصة للمكونات السلبية.

## حدود النسخة الحالية
- هذا مولّد مخطط ثنائي الطرف أولي، وليس بعد محرر KiCad أو مخططاً احترافياً متعدد الأرجل.
- لا يدعم الدارات المتكاملة أو MOSFET/BJT أو الدايود أو المحولات أو الاقتران المغناطيسي أو الموصلات متعددة الأرجل.
- لا يستنتج قيم القطع أو تصنيفاتها من فراغ، ولا يختار تصنيفاً تجارياً غير موثق.
- ملف SPICE يصف العناصر المثالية المدعومة فقط؛ يجب استخدام المحلل الملائم والتحقق من شروط التشغيل قبل إصدار حكم تصميمي.
- لا يُصدر حكم صلاحية بناء كامل قبل إضافة فحص الإجهاد، والتفاوتات، والطفيليات، والحرارة، والحماية، وتوافق الأرجل لكل نوع عنصر.

## شروط الترقية
لا ينتقل من Prototype إلى Validated إلا بعد:
1. اختبارات وحدات مستقلة للمخطط وBOM وSPICE.
2. اختبارات رفض للمدخلات الناقصة وغير الصحيحة.
3. مقارنة netlist مع اتصالات الرسم لنفس المواصفة.
4. اختبارات مرجعية معروفة للمحاكاة الكهربائية المناسبة.
5. إضافة نماذج pin-level موثقة للمكونات متعددة الأرجل قبل دعمها.

## حالة التنفيذ
- Prototype: منفذ ومضاف إلى منفذ الأدوات الآمن.
- Validated: لم يُعلن بعد؛ ينتظر اجتياز CI ومراجعة مخرجات المخطط والـnetlist.
- Implemented: لا تُستخدم هذه الحالة لمجرد وجود الملف.
