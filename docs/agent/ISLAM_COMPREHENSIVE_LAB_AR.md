# ISLAM FREE AGENT — منظومة المختبر الشامل

## القرار المعماري

المختبر الشامل ليس محاكياً واحداً يدّعي تمثيل كل العلوم. هو **مدير مختبرات** يختار محركاً متخصصاً لكل مهمة، ينشئ تجربة قابلة لإعادة الإنتاج، يشغّلها داخل حدود ثابتة، ثم يتحقق من النتيجة بأداة مستقلة أو بحساب مرجعي. لا يُسمح للوكيل بتحميل إضافات أو أوامر اعتباطية من الإنترنت.

## دورة المختبر الإلزامية

1. تصنيف المهمة وتحديد المجال والظواهر الفيزيائية أو البرمجية المطلوبة.
2. تحديد المختبر المتخصص وقدراته الفعلية؛ إذا لم يكن منفذاً، يصرّح بذلك ولا يخترع نتائج.
3. بناء نموذج يذكر الفرضيات والوحدات والثوابت ومصدر بيانات المواد والمكونات.
4. فحص المدخلات والوحدات والحدود العددية قبل التشغيل.
5. إجراء المحاكاة أو الاختبار مع حفظ نسخة النموذج وإعداداته والبذرة العشوائية عند الحاجة.
6. التحقق المستقل: موازنة الطاقة/الكتلة/الشحنة، قوانين الحفظ، حل تحليلي مرجعي، اختبارات تقارب، أو اختبارات برمجية مستقلة حسب المجال.
7. اختبارات حساسية وعدم يقين وحالات حدية وأعطال آمنة عندما تكون ذات صلة.
8. إنتاج تقرير يحوي النتائج والوحدات ومقاييس الخطأ والقيود ومصادر المعرفة.
9. تقديم المحاكاة الفيزيائية المرجعية كتنبؤ هندسي بسلوك التنفيذ الفعلي ضمن شروط النموذج. ترتفع قوة التنبؤ كلما شملت النمذجة بيانات المكونات الواقعية والتفاوت والطفيليات والحرارة والتوصيلات والحماية. يجب التصريح بالافتراضات ومجال الصلاحية، وعدم تعميم النتيجة خارجها.
10. لا اعتماد لتغيير هندسي أو كتابة في المستودع إلا عبر سياسة الصلاحيات والموافقة المعمول بها.

## المجالات المستهدفة

| المجال | المختبر المطلوب |
|---|---|
| كهرباء وإلكترونيات | DC، AC، RLC، أشباه الموصلات، مضخمات، ضوضاء، تفاوت المكونات |
| أنظمة مضمنة | ESP32/MCU، مؤقتات، مقاطعات، ADC/DAC، استهلاك الطاقة |
| إشارات | أخذ العينات، مرشحات، FFT، ضوضاء، كشف الإشارة |
| برمجيات | بناء، اختبارات وحدات وتكامل، تغطية، تحليل أخطاء |
| رياضيات وفيزياء | حل عددي، تحسين، تحليل أبعاد، حساسية وعدم يقين |
| ميكانيكا | حركة، أحمال، اهتزاز، إجهاد وتعب |
| حرارة وموائع | انتقال حرارة، تدفق، حدود حرارية |
| مواد ومنشآت | خواص المواد، إجهاد وانفعال، نماذج فشل |
| بيانات وتجارب | إحصاء، تكرارية، كشف شذوذ، فواصل ثقة |
| بحث علمي | تتبع المصادر، مصفوفة أدلة، اختبار الادعاءات |

هذه المجالات خريطة التغطية المستهدفة. يستطيع مدير المختبرات إنشاء نماذج وتجارب جديدة بصيغة وصفية آمنة وتركيبها على محركات معتمدة؛ أما إضافة محرك تنفيذي جديد فتحتاج قالباً محدوداً واختبارات مرجعية قبل تفعيله.

## حالة التنفيذ الحالية

- منفذ: مختبر DC للمقاومات ومصادر الجهد المثالية بطريقة Modified Nodal Analysis، مع فحص KCL.
- منفذ: مختبر RLC متسلسل أحادي الحلقة: تحليل AC بالطور والممانعة ومعامل القدرة، ومحاكاة transient لمصدر خطوة DC بمكامل RK4 وخطوة زمنية محدودة.
- منفذ: محلل شبكات AC خطية متعددة العقد بطريقة MNA للعناصر R وL وC ومصادر الجهد المثالية، مع فحص KCL والقدرة الحقيقية للمقاومات.
- منفذ: مسار اختبارات البرمجيات المسموح بها.
- مخطط وغير منفذ: الدوائر متعددة الحلقات AC/transient العامة، النبضات ومفاتيح التبديل العامة، أشباه الموصلات، المضخمات، الضوضاء، تفاوت المكونات، MCU، معالجة الإشارات، الميكانيكا، الحرارة، المواد، الإحصاء المتقدم.

محرك RLC العابر الحالي ليس SPICE ولا يحاكي دوائر متعددة الحلقات زمنياً أو نماذج العناصر غير الخطية أو الطفيليات. محلل AC متعدد العقد يدعم الشبكات الخطية RLC فقط. لذلك تنبؤه موثوق ضمن النموذج المثالي المحدد فقط؛ وستكون الخطوة التالية إضافة نماذج مكونات واقعية وطفيليات قبل توسيع مجال التنبؤ.
- يوجد سجل قدرات مركزي في `tools/islam_agent/lab_catalog.py`. لا يمكن اختيار مختبر حالته planned للتنفيذ.

## التشغيل التلقائي للمختبرات

- خلال نافذة العمل المجدولة، يستطيع المدير اقتراح تجربة وتشغيلها تلقائياً إذا كانت جميع خطواتها محاكاة حسابية فقط ضمن محركات DC أو RLC أو AC المعتمدة.
- تُحفظ مدخلات الدارة والنتائج ومؤشر التحقق العددي في سجل مستقل تحت `artifacts/agent/lab_runs/`.
- إذا احتوى الاقتراح على تعديل ملف أو عملية خارج المحاكاة الحسابية، يتوقف المسار التلقائي ويُبقي الاقتراح بانتظار المراجعة والموافقة البشرية.
- لا يتصل هذا المسار بدارة حقيقية أو مصدر طاقة أو أجهزة قياس؛ المحاكاة لا تعني قياساً مادياً.

## عقد إضافة أي مختبر جديد

كل مختبر جديد يجب أن يقدّم:
- وصفاً صريحاً للنطاق والظواهر التي يمثلها وما لا يمثله.
- مخطط مدخلات صارماً، تحقق وحدات وحدود، وحدود CPU/ذاكرة/زمن.
- محركاً قابلاً للتكرار ولا يقبل أوامر حرة من النموذج.
- اختبارات مرجعية معروفة النتائج، وحالات فشل ومدخلات عدائية.
- تحققاً مستقلاً ومقاييس خطأ وتقارب عند الحاجة.
- تقرير نتائج آلياً ومصدر كل ثابت أو خاصية مادة/مكوّن.
- موافقة بشرية قبل أي تحكم بأجهزة مادية أو طاقة أو حركة أو مواد خطرة.

## السلامة والصدق العلمي

المحاكاة الفيزيائية الجيدة أداة تنبؤ هندسي أساسية، وتستطيع إثبات سلوك الدارة ضمن النموذج والفرضيات المعتمدة. تُحسّن دقتها بنماذج المكونات الفعلية والتفاوت والطفيليات والحرارة والتوصيلات. التحكم المادي المباشر يبقى مجالاً منفصلاً يتطلب موافقة وحماية مناسبة؛ وهذا لا ينتقص من قيمة البرهان والمحاكاة العلمية.

## بوابة القبول

لا يعتبر المختبر جاهزاً إلا بعد نجاح اختبارات الوحدة والمرجع والتكامل، وتوثيق حدود النموذج، ومراجعة النتائج. لا يكفي أن ينجح تشغيل واحد أو أن ينتج النموذج رسماً جميلاً.
