# تدقيق مستقل للمدير المساعد ISLAM FREE AGENT

## الغرض
هذا المسار يفحص المدير المساعد نفسه: ذاكرة المهام، سياسة الاقتراحات، منفذ الأدوات، نقاط الاستئناف، Ollama، جسر HTTPS، ومكونات تطبيق Android الخاصة بالمدير.

## حدود النطاق
- لا يشغّل محاكاة الملف الحلزوني أو اختبارات تصميم الكاشف.
- لا يعدّل ذاكرة المشروع أو ملفات المصدر.
- لا يكتب إلى GitHub ولا ينشئ commits أو يدمج Pull Requests.
- لا يعلن أن Ollama أو الهاتف متصلان فعلياً؛ هذه تحتاج اختبار جهاز حقيقي.

## التشغيل
من جذر المستودع:

```bash
python3 tools/islam_agent/manager_audit.py
```

تستخدم الأداة قائمة ثابتة من اختبارات المدير، ومهلة قصوى 180 ثانية، وتفشل مغلقة عند نقص الملفات أو فساد الذاكرة أو انتهاء المهلة.

## العلاقة بالتدقيق الهندسي
يبقى التدقيق الهندسي العام منفصلاً. نجاح تدقيق المدير لا يعني نجاح المحاكاة الهندسية، ونجاح المحاكاة لا يعني أن المدير جاهز للاتصال الميداني.
