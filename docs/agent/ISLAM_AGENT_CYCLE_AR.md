# تشغيل دورة المدير المساعد المحلية

## الوظيفة الحالية

يضيف `tools/islam_agent/agent_cycle.py` دورة تدقيق قابلة للتكرار. في كل دورة:

1. يقرأ ذاكرة المشروع ويتحقق من بنيتها.
2. يختار أول مهمة `in_progress` للاستئناف، وإلا أول مهمة `pending`.
3. يشغّل `audit.py` باختبارات المشروع الهندسية واختبارات المدير المساعد.
4. يحفظ تقرير التدقيق وسجلاً زمنياً بصيغة JSONL في `artifacts/agent/`.

هذه الدورة للمراقبة والتحقق فقط. لا تعدّل الذاكرة أو المصدر، ولا تنفذ أوامر النموذج، ولا تتصل بـGitHub، ولا تدمج PR. كما أنها لا تحتاج Ollama؛ تشغيل النموذج المحلي يبقى مرحلة منفصلة لم تُثبت بعد.

## التشغيل

دورة واحدة:

```bash
python3 tools/islam_agent/agent_cycle.py
```

تكرار كل ست ساعات حتى الإيقاف اليدوي:

```bash
python3 tools/islam_agent/agent_cycle.py --repeat --interval-seconds 21600
```

الحد الأدنى للفاصل في وضع التكرار خمس دقائق. أوقف العملية بـ `Ctrl+C`. يمكن تغيير مكان السجل والتقارير عبر `--log` و`--reports`.

## ما الذي يعنيه التشغيل المتواصل؟

يستمر التكرار ما دامت العملية تعمل والحاسوب مستيقظاً. بعد إغلاق الطرفية أو إطفاء الجهاز تتوقف الدورة. التشغيل الدائم بعد إعادة التشغيل يحتاج خدمة نظام مثل systemd أو Windows Task Scheduler على جهاز دائم التشغيل؛ لم تُفعّل خدمة نظام على جهاز المستخدم من هذا المستودع.

GitHub Actions في هذا PR يختبر التغييرات عند push وPull Request. لا نضيف جدولة إلى فرع هذا PR على أنها فعالة: GitHub يشغّل أحداث schedule من الفرع الافتراضي فقط، والفرع الافتراضي للمستودع هو `main`، ولم نعدّله.

## حدود الدليل

نجاح التدقيق يعني اجتياز الفحوص والاختبارات البرمجية فقط. لا يثبت صحة النموذج الفيزيائي أو محاثة الملف أو عمق الكشف أو الأداء الميداني. كل نتيجة محاكاة تبقى منفصلة عن القياس الحقيقي.
