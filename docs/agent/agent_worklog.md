# سجل عمل ISLAM FREE AGENT

هذا الملف سجل تغييرات الوكيل المعتمدة. لا يُعتبر أي تعديل مقبولاً لمجرد أن النموذج اقترحه؛ يلزم موافقة بشرية ونتيجة تحقق فعلية.

## دورة العمل

1. قراءة المهمة والملفات المحددة.
2. إنشاء اقتراح يتضمن المسار والمحتوى الكامل للملف عند الكتابة.
3. عرض التغيير للمستخدم للمراجعة.
4. انتظار عبارة الموافقة الحرفية.
5. كتابة ذرية إلى قائمة المسارات المسموحة فقط.
6. تشغيل الاختبارات المحددة وحفظ checkpoint لكل خطوة.
7. عند فشل الاختبار، إيقاف الخطة مع حفظ ما اكتمل لإعادة المحاولة دون تكرار الخطوات الناجحة.

## حدود النسخة

- لا أوامر shell حرة.
- لا حذف ملفات.
- لا تعديل للرموز أو الأسرار أو GitHub Actions أو سياسة الأمان أو منفذ الأدوات أو ذاكرة المشروع.
- لا commit أو push أو merge تلقائي.
- الكتابة المحلية لا تعني أن التعديل وصل إلى GitHub؛ يلزم مسار مراجعة ونشر مستقل.
