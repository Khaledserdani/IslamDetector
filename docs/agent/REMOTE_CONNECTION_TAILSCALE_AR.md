# الاتصال البعيد الآمن — ISLAM FREE AGENT

## الهدف

يتيح هذا المسار للهاتف الوصول إلى جسر الكمبيوتر عبر الإنترنت من أي شبكة، من دون فتح منفذ عام في الراوتر، ومن دون استضافة خادم مدفوع. يمر الاتصال عبر شبكة Tailscale الخاصة (Tailnet)، وليس عبر عنوان عام مكشوف.

## المتطلبات

- تثبيت Tailscale على الكمبيوتر والهاتف.
- تسجيل الجهازين في شبكة Tailnet واحدة وبهوية موثوقة.
- إبقاء الكمبيوتر متصلاً بالإنترنت ومشغلاً، مع Ollama والجسر.
- تثبيت Python وOpenSSL وOllama على الكمبيوتر كما هو موضح في دليل التشغيل الأساسي.
- خطة Tailscale Personal مجانية للاستخدام الشخصي غير التجاري، وتشمل حتى 6 مستخدمين وأجهزة مستخدم غير محدودة وفق صفحة الأسعار الرسمية. لا تفترض أن الخطة المجانية مناسبة للاستخدام التجاري أو لكل إعداد مؤسسي.

## إعداد الكمبيوتر

1. ثبّت Tailscale وسجّل الدخول إلى الحساب الشخصي.
2. افتح الطرفية ونفّذ:

```bash
tailscale status
tailscale ip -4
```

3. تأكد أن عنوان IPv4 يبدأ ضمن المجال `100.64.0.0/10` (من 100.64.0.0 إلى 100.127.255.255).
4. من جذر مستودع IslamDetector شغّل:

```bash
python tools/islam_agent/run_bridge.py --tailscale --model "اسم-النموذج-المثبت"
```

5. احتفظ بعنوان Tailscale وبصمة شهادة SHA-256 ورمز الاقتران المؤقت. لا تنشرها ولا ترسلها إلى أشخاص آخرين.

يستمع الجسر على واجهة Tailscale المحددة فقط. لا تستخدم Tailscale Funnel، ولا تفتح المنفذ 8765 على الإنترنت العام، ولا تغيّر Ollama ليقبل اتصالات خارج `127.0.0.1:11434`.

## إعداد الهاتف

1. ثبّت تطبيق Tailscale الرسمي على Android.
2. سجّل الدخول إلى شبكة Tailnet نفسها.
3. افتح ISLAM FREE AGENT.
4. أدخل عنوان Tailscale IPv4 للكمبيوتر، والمنفذ 8765، وبصمة الشهادة، ورمز الاقتران.
5. افحص حالة الجسر ثم اعرض المهام واطلب الاقتراحات.

يمكن أن يكون الهاتف على بيانات الهاتف 4G/5G والكمبيوتر على شبكة منزلية مختلفة. لا يلزم أن يكونا على Wi-Fi نفسها. يجب أن يكون الجهازان متصلين بـTailscale وأن يكون الكمبيوتر والجسر يعملان.

## ما الذي يحمي الاتصال؟

- Tailscale يربط الجهازين داخل شبكة خاصة مشفرة باستخدام WireGuard؛ وقد يكون النقل مباشراً أو عبر مرحّل DERP عند تعذر الاتصال المباشر.
- الجسر يضيف HTTPS مع تثبيت بصمة شهادة الخادم.
- رمز اقتران لمرة واحدة صالح لخمس دقائق، ثم رمز جلسة عشوائي.
- حدود للمحاولات ومعدل الطلبات وحجم الاستجابة.
- لا تُفتح واجهة Ollama ولا أوامر shell على الإنترنت.
- تظل موافقة المستخدم مطلوبة قبل تنفيذ أي اقتراح أو كتابة ملفات.

## حدود يجب معرفتها

- هذا اتصال بعيد بين جهازين، وليس استضافة سحابية: إذا أُطفئ الكمبيوتر أو انقطع الإنترنت عنه، يتوقف المحرك حتى يعود.
- Tailscale خدمة خارجية لها خطة مجانية وشروط استخدام وحدود قابلة للتغيير؛ راجع صفحة الأسعار قبل الاعتماد طويل الأمد.
- نجاح اختبارات العناوين لا يثبت اتصال هاتف فعلي. يلزم اختبار قبول بجهازين على شبكتين مختلفتين، ثم توثيق النتيجة.
- إذا لم يتوفر Tailscale أو لم ترغب باستخدامه، يبقى وضع LAN القديم متاحاً بالأمر المعتاد.

## الاختبارات المطلوبة قبل إصدار APK

1. اختبارات Python: قبول RFC1918 وTailscale CGNAT فقط، ورفض العناوين العامة والخارجية.
2. اختبارات Android: قبول 100.64.0.0/10 ورفض 100.63.255.255 و100.128.0.1.
3. اختبار TLS pinning الصحيح والخاطئ.
4. اختبار الاقتران وانتهاء الرمز وإبطال الجلسة.
5. تجربة فعلية: الكمبيوتر على إنترنت منزلي والهاتف على بيانات الهاتف.
6. اختبار توقف الكمبيوتر أو Tailscale ثم استعادة الاتصال.
7. تأكيد أن Ollama لا يستمع إلا على loopback.

## تشغيل أسهل على Windows

أضفنا مشغّلاً يفحص المتطلبات قبل تشغيل الجسر، دون تنزيل برامج أو نماذج أو إنشاء اشتراكات تلقائياً:

1. ثبّت Python 3 وOpenSSL وOllama وTailscale على الكمبيوتر، وسجّل الدخول إلى Tailscale.
2. افتح Ollama واتركه يعمل، ثم تأكد أن النموذج المطلوب ظاهر في:
   ```powershell
   ollama list
   ```
3. من مجلد المشروع، انقر نقراً مزدوجاً على:
   `tools/islam_agent/start_remote_bridge_windows.bat`
4. اكتب اسم النموذج تماماً كما يظهر في عمود NAME. يمكن أيضاً تمريره إلى PowerShell:
   ```powershell
   .\tools\islam_agent\start_remote_bridge_windows.ps1 -Model "اسم-النموذج"
   ```
5. يعرض الجسر عنوان Tailscale وبصمة TLS ورمز الاقتران المؤقت في نافذة الكمبيوتر. أدخل القيم في التطبيق على الهاتف.
6. لإيقافه اضغط Ctrl+C في النافذة نفسها.

المشغّل لا يثبت Tailscale أو Python أو Ollama ولا يحمل نموذجاً كبيراً تلقائياً. إذا ظهر نقص في أحدها، ثبّته يدوياً ثم أعد تشغيل الملف. لا تشارك رمز الاقتران أو بصمة الشهادة علناً.
