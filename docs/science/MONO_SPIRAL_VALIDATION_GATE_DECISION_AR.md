# محضر تثبيت بوابة التحقق — Mono Spiral PI 35×35 cm
التاريخ: 2026-11-20
المستودع: Khaledserdani/IslamDetector
الفرع: feature/islam-lab-searchcoil-redesign
الحالة: قرار دراسة مثبت؛ لا يعني اعتماد ملف تصنيع نهائي.

## القرار المثبت
يستمر المسار النشط على Mono Spiral PI الأحادي 35×35 cm. يبقى DD32 مرجع مقارنة تاريخياً منفصلاً، ولا تُنقل مواصفاته إلى هذا المسار. لا يُعلن فائز ولا تصدر قائمة شراء نهائية قبل إغلاق بوابات التحقق أدناه.

## قواعد العمل الملزمة
1. عدم اعتبار نتائج المحاكاة أو نجاح CI قياسات فيزيائية.
2. عدم اعتماد المحاثة أو المقاومة أو تيار النبضة أو زمن التعافي كقيم نهائية قبل إعادة الحساب والتحقق والقياس.
3. لا تكفي قيمة L أو كثافة التيار في الهدف لترتيب الملفات؛ معيار المقارنة هو فرق استجابة RX بين حالة الهدف وحالة عدم وجوده ضمن نافذة استقبال قابلة للتنفيذ.
4. إبقاء فرع إعادة التصميم منفصلاً عن فرع المختبر الأساسي بسبب تباعد تاريخي ظاهر في مقارنة Git؛ لا دمج ولا تعديل main ضمن هذا القرار.
5. عدم تغيير دائرة القدرة أو الحماية أو AFE/ADC أو BOM النهائي قبل إثبات متطلبات الملف والنبضة والاستقبال.

## بوابات التحقق بالترتيب
### A — تدقيق المحاثة والهندسة
- إعادة إنتاج مسار اللفات الفعلي وأبعاد الأطراف والانتقالات.
- مقارنة حسابات مستقلة مناسبة للحلزون المربع، مع توثيق الفرضيات وتعريف pitch مقابل clearance.
- إجراء تقارب تقسيم مسار السلك نفسه، لا حلقات الهدف وحدها.
- فحص الحساسية لتعريف أبعاد الموصل والزوايا وموقع بداية/نهاية اللف.
- اعتبار أي تقديرات سابقة للمحاثة مؤقتة حتى إعادة إنتاجها والتحقق منها.

### B — المجال وتغطية سطح الملف
- حساب المجال/الاقتران في المركز والحواف ونقاط وسيطة.
- اختبار حساسية موضع الهدف وعمقه واتجاهه وحجمه ومادته.
- عدم استنتاج عمق كشف مضمون من هذه الحسابات.

### C — الهدف والاستجابة العابرة
- تدقيق نموذج الحلقات المكافئة وحدوده، ومقارنة حالة محورية مرجعية مستقلة.
- زيادة دقة تمثيل الهدف وإجراء تقارب مكاني وزمني موثق.
- عدم اعتبار النموذج الحلقي بديلاً عن FEM حجمي أو قياس هدف حقيقي.

### D — RX وواجهة الاستقبال
- حساب الفيض المرتبط بالملف ثم V_RX = -d(lambda_RX)/dt.
- فصل اقتران TX المباشر عن مساهمة الهدف، ومقارنة target/no-target.
- تحديد زمن التعافي والتشبع ونافذة القياس الممكنة.
- تمرير الموجة إلى نموذج AFE مع وسم حدوده؛ لا توصيل الملف مباشرة بمدخل ADC.

### E — المقارنة والاختيار
- مقارنة المرشحين تحت تيار/طاقة نبضة وإثارة وهدف ووسط وشروط قياس موحدة.
- ترتيبهم وفق SNR وفرق استجابة RX، وتغطية السطح، والاستقرار، وزمن التعافي، والحرارة والوزن وقابلية التصنيع.
- إبقاء القياسات الميدانية المستقلة شرطاً قبل إعلان أداء نهائي.

## تصنيف الأدلة
كل نتيجة يجب أن تحمل أحد الأوصاف: analytical estimate / simulated / measured / independently validated. لا ترفع النتيجة إلى measured أو validated بسبب نجاح اختبار برمجي أو workflow.

## حالة التثبيت
- مثبت: مسار البحث Mono Spiral PI 35×35 cm هو المسار النشط.
- مثبت: DD32 مرجع منفصل فقط.
- مثبت: ترتيب بوابات التحقق ومعايير المقارنة وقواعد عدم الشراء/الاعتماد المبكر أعلاه.
- غير مثبت: قيمة L النهائية، R الفعلية، تيار وعرض النبضة، جهد الإطفاء، نافذة RX، أفضل هندسة تصنيع، عمق الكشف، ودائرة القدرة وAFE النهائية.
- الخطوة التنفيذية التالية: تدقيق حساب المحاثة وتقارب مسار اللفات، ثم المجال المكاني، ثم نموذج الهدف وRX/AFE.

هذا المحضر يثبت منهج القرار ونطاق العمل، ولا يثبت صحة أي رقم أداء لم يُعد حسابه أو قياسه.
