## 4. تعريف الكمية التي سيجري الإبلاغ عنها

يعرف ملف GetDP كمية التكامل:

`J2(t) = \int_{V_{Al}} |J(r,z,t)|^2\,dV`

ثم يحسب المحلل:

`J_{RMS,volume}(t) = sqrt(J2(t) / V_{Al})`

وحجم نموذج قرص الألمنيوم المحوري الحالي:

`V_Al = pi * (0.250 m)^2 * 0.005 m`

هذه كمية RMS حجمية لكثافة التيار المستحث، وليست شدة المجال المغناطيسي، ولا جهد ملف RX، ولا عمق كشف.
